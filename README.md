# MesLang

音声作品の脚本、漫画のネーム、アニメの字コンテに使える、**実験的な軽量テキスト**の仕様を育てているリポジトリです。

以前の [Mes](https://mesdoc.iranika.info/) から、「記号でさっと書いて、意味はあとから足す」「原稿と、読みやすい台本は分ける」という考え方を引き継ぎつつ、漫画やアニメにも使いやすく、AI にも読みやすい形へ作り直しています。

> まだ安定版ではありません。大きく変わることもあります。変更の経緯は ADR（意思決定の記録）に残します。

## 30 秒でわかる書き方

```mes
@にか :表情 微笑
#駅前。夕方の雑踏。
$雑踏のざわめき
!正面
あ、キタキタ。待たせるなんて失礼だぞ。

@こいと
そういうニカちゃんも、ついさっき来たばかりじゃないですか。
#少し呆れた感じ
```

- `@` … だれが話しているか
- `#` … ト書き・状況
- `$` … 音のこと
- `!` … 音の位置や空間
- `:key value` … 表情などの属性（キャラ名はそのまま）
- 空行で **ピース**（ひとまとまり）を区切ります

漫画では `%`（コマ）なども使います → [メディアプロファイル](docs/spec/03-media-profiles.md)  
（サンプルのそばに [参考画像](examples/manga/) もあります）

## 三つの層

1. **MesLang** … 人が書く、軽いテキスト
2. **Medo** … ツールや AI が共有する中間データ
3. **二次ツール** … 台本・ネーム・字コンテなど、「読みやすさ」を担う側

書きやすさは MesLang が、読みやすさは二次ツールが担当します。

## 旧 Mes との関係

MesLang は、Mes のあとを考える仕様です。  
なじみのある記号（`@ # $ ! & ?`）はそのまま残し、属性やコマ／カット、AI 向けの読み方ガイドを足していきます。  
これまでの Mes テキストも、できるだけそのまま取り込みたいと考えています。

## ライセンス / クレジット

実験プロジェクトです。仕様やサンプルの利用に許諾は不要です。
