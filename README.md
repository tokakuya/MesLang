# MesLang

音声作品の脚本・漫画のネーム・アニメーションの字コンテとして使える、**実験的な軽量記述言語**の仕様策定リポジトリです。

旧来の [Mes](https://mesdoc.iranika.info/) の哲学（記号による速記 × 意味デコレーション × 原稿と台本の分離）を引き継ぎつつ、メディア横断と AI 可読性を前提に再設計します。

> 安定版はありません。破壊的変更は当たり前です。仕様は ADR（意思決定記録）で追跡します。

## いま優先する領域

| 優先度 | 領域 | 当面のゴール |
|--------|------|----------------|
| 1 | 音声作品 | Mes 互換の速記と音響デコレーション |
| 1 | 漫画ネーム | コマ・表情・構図を速記できる |
| 2 | アニメ字コンテ | カット・カメラ・タイミング |
| 3 | ゲーム（VN） | 選択肢・分岐は後回し |

## 30 秒でわかる記法

```mes
@にか :表情 微笑
#駅前。夕方の雑踏。
$雑踏のざわめき
!正面
あ、キタキタ。待たせるなんて失礼だぞ。

@こいと
そういうニカちゃんも、ついさっき来たばかりじゃないですか。
#少し呆れた感じ
```

- `@` 発言者 / 主体
- `#` ト書き・状況
- `$` 音響
- `!` 音の位置 / 空間
- `:key value` 属性（表情など。キャラ名を汚さない）
- 空行で **ピース**（最小の意味まとまり）を区切る

漫画向けは `%`（コマ）などを追加します → [メディアプロファイル](docs/spec/03-media-profiles.md)（サンプル直下に [参考画像](examples/manga/) あり）

## 設計の三層

1. **MesLang** … 人が書く軽量テキスト
2. **Medo** … パーサ / AI が共有する中間データ
3. **二次ツール** … 台本・ネーム・字コンテ・集計などの「読みやすさ」側

書きやすさは MesLang が、読みやすさは二次ツールが担います。

## 旧 Mes との関係

MesLang は Mes の後継仕様検討です。旧デコレーター（`@ # $ ! & ?`）はコアとして残し、属性構文・コマ/カット・AI 向け語彙ガイドを拡張します。既存 Mes テキストは糖衣 / 互換層で取り込めることを目標にします。

## ライセンス / クレジット

実験プロジェクトです。仕様・サンプルの利用に許諾は不要です。  
応援してくれる場合は作品概要などに `MesLang` または `iranika@MesLang` をスペシャルサンクスとして書いてくれると嬉しいです。
