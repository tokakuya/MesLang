# 漫画ネーム用途の見本

`profile: manga` の **原稿**（ネーム用途の記述）です。  
参考画像は原稿の一部ではありません（[ADR 0004](../../docs/decisions/0004-manga-reference-images.md)）。  
テキストと見比べるためのお手本で、**1ページ＝1枚** です。

## 記号の目安

| 記号 | ここでは | メモ |
|------|----------|------|
| `==` | ページの区切り | 紙が変わるところ |
| `%` | コマ | ページの中の区切り |
| `^` | 構図・アングル・大きさ | `1/2コマ` などもここに |
| `#` | 絵にしたい状況・動き | セリフがなくても使える |
| `@` | 吹き出しの話者 | `:吹き出し` やかぎかっこ 3 個目で種類を足せる |
| `:表情` | 話者の顔のニュアンス | かぎかっこ 1 個目でも可 |
| `:姿勢` | 話者の体の向き・手など | かぎかっこ 2 個目でも可 |

くわしくは [03-media-profiles.md](../../docs/spec/03-media-profiles.md) をどうぞ。

## station-name.mes — 駅前の二人（1ページ・会話あり）

ソース: [station-name.mes](./station-name.mes)  
仕様書: [03-media-profiles.md](../../docs/spec/03-media-profiles.md)

```mes
profile: manga
title: 駅前の二人（ネーム）
----
== 1ページ

%1
^俯瞰ぎみ 1/2コマ
#夕方の改札前。人波。にかが焦って入ってくる
$雑踏（小さく）

%2
^にかバストアップ 1/2コマ
@にか :表情 焦り
待たせたな……！

%3
^二人を入れる引き
#こいとが柱の陰から半歩出る
@こいと :表情 呆れ
待ちくたびれましたよ

%4
^こいと寄り（汗） 2/3コマ
@こいと[からかうように][少し前傾][心の声]
罰として、今日は奢ってくださいね

%5
^にか寄り 1/3コマ
@にか :表情 苦笑い
お手柔らかにお願いします
```

`%4` のかぎかっこ 3 個目 `[心の声]` は、`:吹き出し 心の声` と同じ意味です。

## station-two-pages.mes — 駅前の二人（2ページ）

ソース: [station-two-pages.mes](./station-two-pages.mes)

1ページ見本の続きを、**紙が変わるところ**まで書いた見本です。  
ページが変わったら `==`、各ページのコマは `%1` から数え直します。  
1ページ目は出会い、2ページ目は駅を出て並んで歩くところです。  
`%4` はセリフのない「間」のコマです（音声見本の「ランチへ」と同じ信号待ちの拍）。

参考画像を置くときは、[ADR 0004](../../docs/decisions/0004-manga-reference-images.md) どおり **`==` ごとに1枚**です（任意）。

```mes
profile: manga
title: 駅前の二人（2ページ）
----
== 1ページ

%1
^俯瞰ぎみ 1/2コマ
#夕方の改札前。人波。にかが焦って入ってくる
$雑踏（小さく）

%2
^にかバストアップ 1/2コマ
@にか :表情 焦り :姿勢 前のめり
待たせたな……！

%3
^二人を入れる引き
#こいとが柱の陰から半歩出る
@こいと :表情 呆れ :姿勢 腕を組む
待ちくたびれましたよ

%4
^こいと寄り（汗） 2/3コマ
@こいと[からかうように][少し前傾][心の声]
罰として、今日は奢ってくださいね

== 2ページ

%1
^改札を出て並ぶ引き 1/2コマ
#人波をぬけ、駅前の広場へ歩き出す。肩が並ぶ
$雑踏（少し遠のく）

%2
^にか寄り 1/3コマ
@にか :表情 苦笑い :姿勢 ポケットに手
お手柔らかにお願いします

%3
^こいとバスト 1/3コマ
@こいと[微笑][歩調を合わせる]
奢る側が決める権利、ありますからね

%4
^信号待ち 足元と影 横長
#横断歩道の前で並んで止まる。会話はいったん途切れる
*間
$歩行者信号の音（小さく）

%5
^二人後ろ姿 横長フル
#夕陽のほうへ歩き去る。顔は見せない
*間
$街のざわめき（遠く）
```

## cafe-pose.mes — カフェ・表情と姿勢の練習（会話あり・別シチュ）

ソース: [cafe-pose.mes](./cafe-pose.mes)

駅前とは違う場面で、`:表情` / `:姿勢` とかぎかっこ速記を交互に使った見本です。  
コマ全体の動きは `#`、話者の顔と体は属性へ、と分けて書いています。  
`%7` は、表情・姿勢のやりとりのあとに置く反応コマの例です。

```mes
profile: manga
title: カフェ・表情と姿勢の練習
----
== 1ページ

%1
^店内引き 1/2コマ
#夕方のカフェ。窓際の席。にかが席に着くところ
$店内BGM（小さく）

%2
^にか全身 1/2コマ
@にか :表情 ほっとした :姿勢 椅子に沈む
ふう……やっと座れた

%3
^こいとバスト 1/3コマ
@こいと[微笑][肘をついて顎を支える]
メニュー、まだ見てないんですよね？

%4
^にか寄り 1/3コマ
#メニューを開いて、目を泳がせる
@にか :表情 困り :姿勢 前のめり
……甘いもの、全部美味しそうに見えるんだが

%5
^二人横並び 2/3コマ
@こいと :表情 楽しそう :姿勢 少し身を乗り出す
じゃあ、私が決めます。今日は私が奢りますから

%6
^にかバスト 1/3コマ
@にか[苦笑い][後ずさり気味]
奢る側が決めるのは、ちょっとずるいぞ

%7
^こいと寄り 1/3コマ
#抗議を受けて、くすっと笑う
@こいと :表情 にやり :姿勢 指を一本立てる
ずるいですけど、美味しいものにしますから
```

## silent-panels.mes — 駅前・無言の導入（セリフなし）

ソース: [silent-panels.mes](./silent-panels.mes)

セリフがなくても、`%` と `^` / `#`（必要なら `$` `*`）だけでページが書けます。  
会話の前の空気や、間のコマを置くときの見本です。  
`%6` は、見つける直前の「間」だけを厚くしたコマです（構図メモ＋`*`＋環境音）。

## AI に頼むとき

ネーム起こし・参考画像・ネーム原稿の下書きは、[AI 向けガイド](../../docs/spec/04-ai-reading.md#漫画ネーム起こし) のひな形をどうぞ。  
複数ページなら [station-two-pages.mes](./station-two-pages.mes) を渡し、ページごとに `%` を数え直す前提で頼むと伝わりやすいです。  
不足情報だけの洗い出しや、形チェック→洗い出し→起こしの順番も、同じ文書にあります。

```mes
profile: manga
title: 駅前・無言の導入
----
== 1ページ

%1
^俯瞰 横長フル
#夕方の改札。人波だけ。だれの顔もまだ見えない
$雑踏（遠く）

%2
^足元アップ 1/3コマ
#にかの靴が改札を踏む。影が長い
$靴音（小さく）

%3
^にか後ろ姿 2/3コマ
#人波をかきわけて進む。顔は見せない

%4
^柱の陰 1/2コマ
#こいとが柱にもたれて待つ。表情はまだ読めない
*間

%5
^二人の距離 1/2コマ
#にかが立ち止まって周囲を探す。こいととの目はまだ合わない

%6
^にか横顔と柱の隙間 横長フル
#人波が一瞬途切れる。柱の陰にこいとの気配だけが見える。まだ声は出さない
*間（見つける直前）
$雑踏（一段遠のく）
```
