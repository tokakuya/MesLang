# 漫画ネーム用途の見本

`profile: manga` の **原稿**（ネーム用途の記述）です。  
参考画像は原稿の一部ではありません（[ADR 0004](../../docs/decisions/0004-manga-reference-images.md)）。  
テキストと見比べるためのお手本で、**1ページ＝1枚** です。

## 記号の目安

| 記号 | ここでは | メモ |
|------|----------|------|
| `==` | ページの区切り | 紙が変わるところ |
| `%` | コマ | ページの中の区切り |
| `^` | 構図・アングル・大きさ | `1/2コマ` などもここに |
| `#` | 絵にしたい状況・動き | セリフがなくても使える |
| `@` | 吹き出しの話者 | `:吹き出し` やかぎかっこ 3 個目で種類を足せる |

くわしくは [03-media-profiles.md](../../docs/spec/03-media-profiles.md) をどうぞ。

## station-name.mes — 駅前の二人（1ページ・会話あり）

ソース: [station-name.mes](./station-name.mes)  
仕様書: [03-media-profiles.md](../../docs/spec/03-media-profiles.md)

```mes
profile: manga
title: 駅前の二人（ネーム）
----
== 1ページ

%1
^俯瞰ぎみ 1/2コマ
#夕方の改札前。人波。にかが焦って入ってくる
$雑踏（小さく）

%2
^にかバストアップ 1/2コマ
@にか :表情 焦り
待たせたな……！

%3
^二人を入れる引き
#こいとが柱の陰から半歩出る
@こいと :表情 呆れ
待ちくたびれましたよ

%4
^こいと寄り（汗） 2/3コマ
@こいと[からかうように][少し前傾][心の声]
罰として、今日は奢ってくださいね

%5
^にか寄り 1/3コマ
@にか :表情 苦笑い
お手柔らかにお願いします
```

`%4` のかぎかっこ 3 個目 `[心の声]` は、`:吹き出し 心の声` と同じ意味です。

## silent-panels.mes — 駅前・無言の導入（セリフなし）

ソース: [silent-panels.mes](./silent-panels.mes)

セリフがなくても、`%` と `^` / `#`（必要なら `$` `*`）だけでページが書けます。  
会話の前の空気や、間のコマを置くときの見本です。

```mes
profile: manga
title: 駅前・無言の導入
----
== 1ページ

%1
^俯瞰 横長フル
#夕方の改札。人波だけ。だれの顔もまだ見えない
$雑踏（遠く）

%2
^足元アップ 1/3コマ
#にかの靴が改札を踏む。影が長い
$靴音（小さく）

%3
^にか後ろ姿 2/3コマ
#人波をかきわけて進む。顔は見せない

%4
^柱の陰 1/2コマ
#こいとが柱にもたれて待つ。表情はまだ読めない
*間

%5
^二人の距離 1/2コマ
#にかが立ち止まって周囲を探す。こいととの目はまだ合わない
```
