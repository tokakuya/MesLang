# 漫画ネーム用途の見本

`profile: manga` の **原稿**（ネーム用途の記述）です。  
参考画像は原稿の一部ではありません（[ADR 0004](../../docs/decisions/0004-manga-reference-images.md)）。  
テキストと見比べるためのお手本で、**1ページ＝1枚** です。

## 記号の目安

| 記号 | ここでは | メモ |
|------|----------|------|
| `==` | ページの区切り | 紙が変わるところ |
| `%` | コマ | ページの中の区切り |
| `^` | 構図・アングル・大きさ | `1/2コマ` などもここに。言い方の目安は [構図の語彙ガイド](../../docs/spec/03-media-profiles.md#構図の語彙ガイドよく使う書き方) |
| `#` | 絵にしたい状況・動き | セリフがなくても使える |
| `@` | 吹き出しの話者 | `:吹き出し` やかぎかっこ 3 個目で種類を足せる |
| `:表情` | 話者の顔のニュアンス | かぎかっこ 1 個目でも可 → [用語集](../../docs/spec/05-glossary.md#かぎかっこ速記と属性まぎらわしいことば) |
| `:姿勢` | 話者の体の向き・手など | かぎかっこ 2 個目でも可 |
| `*` | 間やテンポのメモ | 感じとしてのビート。秒数の尺は `&`（ほぼ使わない）→ [用語集](../../docs/spec/05-glossary.md#タイミングとビートまぎらわしいことば) |

くわしくは [03-media-profiles.md](../../docs/spec/03-media-profiles.md) をどうぞ。

## station-name.mes — 駅前の二人（1ページ・会話あり）

ソース: [station-name.mes](./station-name.mes)  
仕様書: [03-media-profiles.md](../../docs/spec/03-media-profiles.md)

```mes
profile: manga
title: 駅前の二人（ネーム）
----
== 1ページ

%1
^俯瞰ぎみ 1/2コマ
#夕方の改札前。人波。にかが焦って入ってくる
$雑踏（小さく）

%2
^にかバストアップ 1/2コマ
@にか :表情 焦り
待たせたな……！

%3
^二人を入れる引き
#こいとが柱の陰から半歩出る
@こいと :表情 呆れ
待ちくたびれましたよ

%4
^こいと寄り（汗） 2/3コマ
@こいと[からかうように][少し前傾][心の声]
罰として、今日は奢ってくださいね

%5
^にか寄り 1/3コマ
@にか :表情 苦笑い
お手柔らかにお願いします

%6
^二人引き 横長
#同じコマのなかで短いやりとり（% は先頭のピースだけ。空行のあとは % なし）
@にか :表情 苦笑い :姿勢 ポケットに手
……わかった。どこ行く？

@こいと :表情 にやり :姿勢 歩調を合わせる
例の店、です

%7
^夕景の駅前 横長
#ナレーション枠で時間と場所を示す（顔のない枠）
@ナレ :吹き出し ナレ
夕方の駅前は、いつもより少し混んでいる。

%8
^店の入り口 引き
#コマの外から店員の声だけ（顔は描かない＝外注ぎ）
@店員[微笑][店内から][外注ぎ]
いらっしゃいませー！
```

`%4` のかぎかっこ 3 個目 `[心の声]` は、`:吹き出し 心の声` と同じ意味です。  
`%6` は、同じコマに二人のセリフを置く例です（`%` は先頭ピースだけ。空行のあとは `%` なし → [用語集（コマとピース）](../../docs/spec/05-glossary.md#コマとピースまぎらわしいことば)）。  
`%7` は **ナレ**（`:吹き出し ナレ`）、`%8` は **外注ぎ**（かぎかっこ 3 個目）です → [吹き出しの書き方](../../docs/spec/03-media-profiles.md#吹き出しの書き方吹き出し-とかぎかっこ)。  
到着の拍を音声側で厚くした例は [station.mes](../audio/station.mes) の「店の前」です。

## station-two-pages.mes — 駅前の二人（2ページ）

ソース: [station-two-pages.mes](./station-two-pages.mes)

1ページ見本の続きを、**紙が変わるところ**まで書いた見本です。  
ページが変わったら `==`、各ページのコマは `%1` から数え直します。  
1ページ目は出会い、2ページ目は駅を出て並んで歩くところです。  
`%4` は **無言コマ** です（音声見本「ランチへ」の音だけの間と同じ信号待ちの拍）。  
呼び分けは [用語集（音だけの間 / 無言コマ）](../../docs/spec/05-glossary.md#セリフのない間音だけの間--無言コマ) / [用語集（コマとカット）](../../docs/spec/05-glossary.md#コマとカットまぎらわしいことば) をどうぞ。

参考画像を置くときは、[ADR 0004](../../docs/decisions/0004-manga-reference-images.md) どおり **`==` ごとに1枚**です（任意）。

```mes
profile: manga
title: 駅前の二人（2ページ）
----
== 1ページ

%1
^俯瞰ぎみ 1/2コマ
#夕方の改札前。人波。にかが焦って入ってくる
$雑踏（小さく）

%2
^にかバストアップ 1/2コマ
@にか :表情 焦り :姿勢 前のめり
待たせたな……！

%3
^二人を入れる引き
#こいとが柱の陰から半歩出る
@こいと :表情 呆れ :姿勢 腕を組む
待ちくたびれましたよ

%4
^こいと寄り（汗） 2/3コマ
@こいと[からかうように][少し前傾][心の声]
罰として、今日は奢ってくださいね

== 2ページ

%1
^改札を出て並ぶ引き 1/2コマ
#人波をぬけ、駅前の広場へ歩き出す。肩が並ぶ
$雑踏（少し遠のく）

%2
^にか寄り 1/3コマ
@にか :表情 苦笑い :姿勢 ポケットに手
お手柔らかにお願いします

%3
^こいとバスト 1/3コマ
@こいと[微笑][歩調を合わせる]
奢る側が決める権利、ありますからね

%4
^信号待ち 足元と影 横長
#横断歩道の前で並んで止まる。会話はいったん途切れる
*間
$歩行者信号の音（小さく）

%5
^二人後ろ姿 横長フル
#夕陽のほうへ歩き去る。顔は見せない
*間
$街のざわめき（遠く）
```

## cafe-pose.mes — カフェ・表情と姿勢の練習（会話あり・別シチュ）

ソース: [cafe-pose.mes](./cafe-pose.mes)

駅前とは違う場面で、`:表情` / `:姿勢` とかぎかっこ速記を交互に使った見本です。  
コマ全体の動きは `#`、話者の顔と体は属性へ、と分けて書いています。  
`%7` は、表情・姿勢のやりとりのあとに置く反応コマの例です。  
`%8` は、`:吹き出し 心の声` を **属性** で書いた例です（駅前見本のかぎかっこ 3 個目と同じ意味）。  
`%9` は、心の声のあとに **ふつうのセリフ** へ戻る例です（`:吹き出し` は付けない。種別はコマごと）。

```mes
profile: manga
title: カフェ・表情と姿勢の練習
----
== 1ページ

%1
^店内引き 1/2コマ
#夕方のカフェ。窓際の席。にかが席に着くところ
$店内BGM（小さく）

%2
^にか全身 1/2コマ
@にか :表情 ほっとした :姿勢 椅子に沈む
ふう……やっと座れた

%3
^こいとバスト 1/3コマ
@こいと[微笑][肘をついて顎を支える]
メニュー、まだ見てないんですよね？

%4
^にか寄り 1/3コマ
#メニューを開いて、目を泳がせる
@にか :表情 困り :姿勢 前のめり
……甘いもの、全部美味しそうに見えるんだが

%5
^二人横並び 2/3コマ
@こいと :表情 楽しそう :姿勢 少し身を乗り出す
じゃあ、私が決めます。今日は私が奢りますから

%6
^にかバスト 1/3コマ
@にか[苦笑い][後ずさり気味]
奢る側が決めるのは、ちょっとずるいぞ

%7
^こいと寄り 1/3コマ
#抗議を受けて、くすっと笑う
@こいと :表情 にやり :姿勢 指を一本立てる
ずるいですけど、美味しいものにしますから

%8
^にか寄り 1/3コマ
#小さくうなずきつつ、心の中でぼやく
@にか :表情 苦笑い :姿勢 肩をすくめる :吹き出し 心の声
……まあ、甘いものなら負けてもいいか

%9
^にかバスト 1/3コマ
#心の声のあと、小さく本音を口に出す（吹き出し種別は付けない＝ふつうのセリフ）
@にか :表情 照れ :姿勢 メニューに視線を落とす
……じゃあ、任せた
```

## silent-panels.mes — 駅前・無言の導入（セリフなし）

ソース: [silent-panels.mes](./silent-panels.mes)

セリフがなくても、`%` と `^` / `#`（必要なら `$` `*`）だけでページが書けます。  
会話の前の空気や、**無言コマ** を置くときの見本です（音声の音だけの間との呼び分けは [用語集](../../docs/spec/05-glossary.md#セリフのない間音だけの間--無言コマ)）。  
`%6` は、見つける直前の「間」だけを厚くしたコマです（構図メモ＋`*`＋環境音）。  
`%7` は、見つけたあとも無言のまま、目が合う拍を `^目線の高さ …` で置いた例です（構図の語彙は [メディアプロファイル](../../docs/spec/03-media-profiles.md#構図の語彙ガイドよく使う書き方)）。  
`%8` は、目が合ったあともセリフを足さず、声を出す直前の一拍です（会話見本の直前まで無言でつなぐ）。  
ここでの `*間` は感じとしてのビートで、音声の `&約1.5秒` のような尺メモとは別です → [用語集（タイミングとビート）](../../docs/spec/05-glossary.md#タイミングとビートまぎらわしいことば)。

## AI に頼むとき

ネーム起こし・参考画像・ネーム原稿の下書きは、[AI 向けガイド](../../docs/spec/04-ai-reading.md#漫画ネーム起こし) のひな形をどうぞ。  
全角の `％` / `＾` / `＊` も半角と同じ意味です（読み取りでは区別しません。新しく書くときは半角が無難）。
渡す見本の目安: 無言の構図は [silent-panels.mes](./silent-panels.mes) の `%7`（目が合う）と `%8`（声を出す直前）、属性の心の声は [cafe-pose.mes](./cafe-pose.mes) の `%8`（戻す口語は `%9`）、かぎかっこの心の声と **同じコマの二人セリフ**（`%6`）は [station-name.mes](./station-name.mes)。  
複数ページなら [station-two-pages.mes](./station-two-pages.mes) を渡し、ページごとに `%` を数え直す前提で頼むと伝わりやすいです。  
不足情報だけの洗い出しや、形チェック→洗い出し→起こしの順番も、同じ文書にあります。

```mes
profile: manga
title: 駅前・無言の導入
----
== 1ページ

%1
^俯瞰 横長フル
#夕方の改札。人波だけ。だれの顔もまだ見えない
$雑踏（遠く）

%2
^足元アップ 1/3コマ
#にかの靴が改札を踏む。影が長い
$靴音（小さく）

%3
^にか後ろ姿 2/3コマ
#人波をかきわけて進む。顔は見せない

%4
^柱の陰 1/2コマ
#こいとが柱にもたれて待つ。表情はまだ読めない
*間

%5
^二人の距離 1/2コマ
#にかが立ち止まって周囲を探す。こいととの目はまだ合わない

%6
^にか横顔と柱の隙間 横長フル
#人波が一瞬途切れる。柱の陰にこいとの気配だけが見える。まだ声は出さない
*間（見つける直前）
$雑踏（一段遠のく）

%7
^目線の高さ 二人バスト 1/2コマ
#柱の陰から半歩出たこいとと、にかの目が合う。まだだれも口を開かない
*間（見つけた直後）

%8
^二人寄り 横長フル
#目が合ったまま一歩近づく。にかが口を開きかけ、まだ声にはならない
*間（声を出す直前）
$雑踏（遠く）
```
