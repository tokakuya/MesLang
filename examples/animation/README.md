# アニメ字コンテの見本

字コンテやカット表の下書き向けの、短い見本です。  
きれいな絵コンテそのものではなく、カット番号・カメラ・尺・セリフをさっと残すための原稿です。

## ファイル

| ファイル | 内容 |
|----------|------|
| [station-conte.mes](station-conte.mes) | 駅前の再会を5カット。カメラ・尺・音に加え、ツール用の `?` メモも混ぜています |

## 読み方のヒント

- `%CUT-…` … カットの区切り（漫画のコマと同じ「画面の区切り」）
- `^` … カメラの動きやレンズ感
- `&` … 秒数の目安
- `#` / `$` … 演技・状況と、聞こえる音
- `?` … 制作ツール向けの逃げ道（レイアウト案や背景 ID など）。仕様は意味を固定しません → [デコレーター仕様の「`?` について」](../../docs/spec/02-decorators.md)

くわしい記号の見比べは [メディアプロファイル](../../docs/spec/03-media-profiles.md) をどうぞ。  
カット表の仮形（二次出力）は [絵コンテ／カット表](../../docs/spec/07-conte-table.md) と、参照パーサの `npm run conte` をどうぞ。
