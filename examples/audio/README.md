# 音声作品の見本

`profile: audio`（または省略時の既定）の原稿です。  
`$`（音）と `!`（位置）の書き方の目安は、[語彙ガイド](../../docs/spec/03-media-profiles.md#音と位置の語彙ガイドよく使う書き方) にまとめています。  
字幕や尺が必要なときだけの `&` も、同じ節に短く書いてあります（漫画の `*間` との呼び分けは [用語集](../../docs/spec/05-glossary.md#タイミングとビートまぎらわしいことば)）。  
絵がないので `%`（コマ／カット）はふつう使いません → [用語集（コマとカット）](../../docs/spec/05-glossary.md#コマとカットまぎらわしいことば)。

## station.mes — 駅前の二人

ソース: [station.mes](./station.mes)

オープニングの会話に、BGM・環境音・左右・遠近のメモを足した見本です。  
セリフの流れは止めず、音まわりだけあとから厚くしています。  
かぎかっこ速記（`@にか[焦り]` / `@にか[思索][ヒソヒソ]`）は、音声では 2 個目が **声質** になります。

二場面目「改札を出て」では、同じピースに `$`（聞こえる音）・`!`（位置）・`&`（字幕／尺）と、話者の `:声質`（属性またはかぎかっこ 2 個目）が並ぶ例を置いています。  
場のアナウンスは `$`、いま話している人の声の出し方は `:声質`、という分け方の練習用です。

三場面目「ランチへ」では、**音だけの間**（セリフのないピース。`$` / `!` / `&` / `#` だけ）で信号待ちの拍を置いてから、また会話に戻ります。  
漫画の **無言コマ** と同じく、音だけの拍も原稿の一部です。同じ信号待ちの拍を漫画側で置いた例は [station-two-pages.mes](../manga/station-two-pages.mes) の2ページ目 `%4` です。  
呼び分けは [用語集](../../docs/spec/05-glossary.md#セリフのない間音だけの間--無言コマ) をどうぞ。

### セリフ文字数を数える（任意）

```bash
cd packages/meslang-ref
npm run count -- ../../examples/audio/station.mes
```

空白を除いたセリフだけの合計です。記号行（`$` や `#` など）は数えません。  
AI に目安だけ聞いて照合するときは、[セリフ文字数の照合](../../docs/spec/04-ai-reading.md#セリフ文字数の照合音声) のひな形をどうぞ。

## 旧 Mes 取り込みの前後

- [mes-import-before.mes](./mes-import-before.mes) … ヘッダー `$title`、章らしい `#オープニング`、行頭 `○` / `◯`、旧流儀の `$ヒソヒソ声`、場の `$` / `!` が混ざった例
- [mes-import-after.mes](./mes-import-after.mes) … 章を `==` にし、柱をト書きへ、話者の声だけ `:声質` へ移したあとの例（場の音と位置はそのまま）

機械が直すのは行頭の `○` / `◯` → `#` だけです。似た形の `〇`（漢数字のゼロに近い形）は柱ではないので直しません。  
`#オープニング` を `==` にするか、`$ヒソヒソ声` を `:声質` へ移すかも人の判断です。  
手順は [06-mes-compat.md](../../docs/spec/06-mes-compat.md)、`$` と `:声質` の分け方は [音声プロファイル](../../docs/spec/03-media-profiles.md#音声質ト書きの分け方) をどうぞ。  
ヘッダーの `$title` は変数で、本文の `$音` とは別ものです（[コア仕様](../../docs/spec/01-core.md#ヘッダーの--と本文の--は別もの) / [用語集](../../docs/spec/05-glossary.md#音声質ヘッダー変数まぎらわしいことば)）。

### 取り込み後 Medo の目視（任意）

```bash
cd packages/meslang-ref
node --experimental-strip-types src/cli.ts --compat --validate ../../examples/audio/mes-import-before.mes
```

確認の観点は [取り込みガイドの目視節](../../docs/spec/06-mes-compat.md#取り込み後-medo-の目視任意) と同じです（セクションはまだ1つ、柱は `comment`、声質候補はまだ `$`）。

## AI に頼むとき

台本化・音声原稿の下書き・旧 Mes 取り込みの手伝いは、[AI 向けガイド](../../docs/spec/04-ai-reading.md#音声台本化) のひな形をコピーしてください。  
セリフ文字数の照合はツールの `--count` が本命で、AI 用のひな形は [セリフ文字数の照合](../../docs/spec/04-ai-reading.md#セリフ文字数の照合音声) にあります。
