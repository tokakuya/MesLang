# コア構造

MesLang の「骨組み」です。どのメディアでも共通の約束ごとをまとめています。

## 文字と改行

- 文字コードは UTF-8 です
- 改行は LF にそろえて扱います（CRLF でも大丈夫です）
- 全角と半角の記号は同じものとして扱います（`@` と `＠`、`%` と `％` など）。呼び分けは [用語集](05-glossary.md#全角半角の行頭記号まぎらわしいことば) をどうぞ
- 「デコレーター」と「行頭記号」は同じ仲間です → [用語集](05-glossary.md#デコレーターと行頭記号まぎらわしいことば)

## 文書の組み立て

```
[ヘッダー]
----
[ボディ]
```

ヘッダーはなくても構いません。`----` だけの行が境目です。  
ボディは **セクション** と **ピース** でできています。

### セクション（任意）

行頭が `==` の行は、セクションの見出しです。  
章やページなど、大きめの区切りに使います。文書構造の区切りとして正式に使うのは、この形だけです。

```mes
== 第一章 / 駅前
```

旧 Mes の `#第一章` のような行は、コアではふつうのト書きとして扱います。  
セクションへ寄せる変換は人手（または取り込みツールの任意処理）です（[ADR 0003](../decisions/0003-hash-is-comment-not-section.md)、[取り込みガイド](06-mes-compat.md)）。

### ピース

**1 行以上の空行**で区切られた塊がピースです。  
脚本のうえでの、いちばん小さなまとまりだと思ってください。

```mes
@にか
こんにちは。

@こいと
こんにちは。
```

上は 2 つのピースです。

## 行の種類

ボディの、空でない行は次のいずれかです。

1. **デコレーター行** — 行頭が記号（`@` `#` `$` など）
2. **属性の続き** — 行頭が `:`（直前の記号や、そのピースに付きます）
3. **セリフ行** — 上のどれでもない行（ピースの中でつなげられます）
4. **セクション行** — `==` で始まる行

**コメントアウト**（読み飛ばす行）は、行頭 `//` です（v0）。  
`#`（ト書き）とは別ものです。  
旧 Mes 由来の記法（`○` 柱など）は、v0 コアでは扱いません。取り込み前に互換レイヤで直します（[06-mes-compat.md](06-mes-compat.md)、[用語集](05-glossary.md#採用しないコアに入れない案)）。

## ピースが持つ情報（イメージ）

ツールが読み取ったあと、だいたい次のようなまとまりになります。

```
Piece {
  dialogue: string          # セリフ
  decorators: Decorator[]   # 記号の行（出てきた順）
  attrs: { key: value }     # ピース直下の属性（あまり使いません）
}
```

同じ種類の記号が複数あれば、値は配列か、改行でつなぐ形にします（参照パーサは配列です）。

## 速記の橋渡し（DoFlat）

パースする前に、なじみのある書き方を正規の形へ直します。  
この処理を DoFlat（参照パーサの `doFlat`）と呼びます。

v0 で公式に含むもの:

| 入力 | 正規化後 |
|------|----------|
| `名前「セリフ」` | `@名前` + セリフ |
| `名前\tセリフ` | 同上 |
| `名前    セリフ`（空白4つ） | 同上 |

v0 では含めないもの:

| 入力 | 扱い |
|------|------|
| `#第一章`（旧柱書き） | ト書きのまま。`==` へはコアでは変換しません |

速記は、「よく知られた脚本の書き方」への橋です。新しい速記も、コアを壊さずに足せます。

## ヘッダー変数（任意）

ヘッダー（`----` より前）には、作品のメタ情報を書けます。  
なくても大丈夫です。書かなければ `profile` は音声（`audio`）扱いです。

### 書き方

次の 2 形を受け付けます（どちらも同じ意味です）。

| 形 | 例 |
|----|----|
| `key: value`（おすすめ） | `profile: audio` |
| `$key value`（旧 Mes なじみ） | `$title 駅前の二人` |

全角の `：` も使えます（`profile： audio`）。

### v0 でよく使うキー

| キー | 意味 | 例 |
|------|------|-----|
| `profile` | メディアプロファイル | `audio` / `manga` / `anime` |
| `title` | 作品や場面の題名 | `駅前の二人` |
| `bracket-keys` | かぎかっこ速記のキー順（上書き） | `表情, 姿勢, 声質`（[ADR 0007](../decisions/0007-profile-bracket-keys.md)） |

ほかのキーもそのまま残します（ツールや人のメモ用）。参照パーサは文字列として保持します。

```mes
profile: audio
title: 駅前の二人
----
@にか
...
```

### ヘッダーの `$` と本文の `$` は別もの

| 場所 | `$` の意味 | 例 |
|------|------------|-----|
| ヘッダー（`----` の前） | 変数の書き方（`$key value`） | `$title 駅前` |
| ボディ（`----` の後） | 音のデコレーター | `$雑踏` `$BGM 夕方の駅` |

旧 Mes から移すとき、ヘッダーに `$title …` が残っていても大丈夫です。  
本文の `$ヒソヒソ声` のような行は音のメモのままです（話者の声質へ移す手順は [取り込みガイド](06-mes-compat.md)）。  
呼び分けの早見は [用語集](05-glossary.md#音声質ヘッダー変数まぎらわしいことば) をどうぞ。
