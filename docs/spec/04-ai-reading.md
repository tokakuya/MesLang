# AI が MesLang を読むための約束

MesLang はパーサだけでなく、ネーム生成・字コンテ起こし・台本整形などを行う AI の入力にもする。

## 読み手（AI）への基本指示（コピー用）

```
あなたは MesLang 原稿を読む。
- 空行区切りの「ピース」が時間/コマ/発話の単位
- 行頭記号: @話者 #ト書き $音 !位置 &タイミング %コマ/カット ^カメラ *ビート
- 文書の章・ページ区切りは == セクション。#第一章 のような行もト書きであり章見出しではない
- :key value は属性。特に :表情 はキャラIDを変えずに表情を表す
- 記号は構造、# と属性値の自然言語はニュアンス
- // 行はコメントアウト（無視）。# と混同しない
- 書いていない情報は推測で断定せず、不足として列挙する
```

## 著者側の書き方（AI に渡すとき）

1. **構造は記号で** — 誰が話すか、何コマ目かは `@` `%` で明示
2. **ニュアンスは字句で** — 「なんか悲しい感じ」より「口元は笑っているが目が合わない」
3. **曖昧さを残すなら意図的に** — `#（表情は絵師に委ねる）` のように書く
4. **プロファイルを明示** — ヘッダー `profile: manga` などで出力の期待を固定

## AI 出力側に MesLang を書かせるとき

- まずピース分割を守らせる（1 発話 / 1 コマ意図ごとに空行）
- 装飾を盛りすぎない（必須はセリフと、メディア上どうしても要るもの）
- 未知の記号を発明させない。足りなければ `#` か `?` か属性キーを使う

## パーサとの役割分担

| 役割 | パーサ | AI |
|------|--------|-----|
| ピース分割・記号割当 | 決定的に行う | 補助可だが最終はパーサ |
| 表情とキャラIDの分離 | 属性として保持 | 集計・アイコン割当に利用 |
| 絵の構図の具体化 | しない | `#` `^` `%` から提案 |
| 欠落の補完 | しない | 提案として出し、原文は維持 |

## プロンプト雛形

### 漫画ネーム起こし

```
次の MesLang（profile: manga）を、ページごとのネーム概要にして。
各コマについて: 構図 / キャラ配置 / 表情 / セリフ を短く。
原文にない設定は「提案:」と印をつけて分けて書く。
```

### 漫画参考画像（サンプル提示・ネーム確認）

```
次の MesLang（profile: manga）を、== セクション（ページ）ごとに白黒漫画ネーム風の1枚絵として生成する。
1ページ＝1画像。コマ割り・吹き出し・表情は % ^ # @ とセリフから読み取る。
コマの読み順は日本の漫画どおり右→左、上→下（横並びなら右コマが先）。吹き出し内は縦書き。
^ に書かれた 1/2コマ・2/3コマ などのサイズメモはコマ割りに反映する。
画像は原稿に埋め込まず、サンプルテキストの直下に参考として置く（人がテキストと見比べる用）。
```

（参考画像は二次成果物。詳細は [ADR 0004](../decisions/0004-manga-reference-images.md)。実例は [examples/manga/](../../examples/manga/)）

### 音声台本化

```
次の MesLang（profile: audio）を、話者名付き台本形式に整形して。
$ と ! は音響メモ欄へ。# はト書き欄へ。セリフ本文は装飾記号を付けない。
```
