# MesLang v0 — 概要

ステータス: **Draft / Experimental**  
前提バージョン: `meslang/0.0.x`

## 一言で

MesLang は、セリフを中心に置き、その前後に意味（発言者・ト書き・音・コマなど）を **デコレート** していく軽量テキストである。

## 旧 Mes からの継承

残すもの:

- ピース（空行区切り）
- デコレーター行頭記号
- 前置 / 後置の自由
- 糖衣構文（`名前「セリフ」`）
- ヘッダー（`----`）

足すもの:

- デコレーター属性（`:key value`）
- メディアプロファイル（特に `%` コマ/カット）
- AI 向けの語彙と解釈ガイド
- 中間データ Medo の明示スキーマ

## 非目標（v0）

- 完全な組版・台本レイアウト
- ゲーム分岐 DSL
- 安定した後方互換保証
- 専用エディタ必須化
