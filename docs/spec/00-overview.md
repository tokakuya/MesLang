# MesLang v0 — 概要

ステータス: **下書き / 実験中**  
いまの版: `meslang/0.0.x`

## ひとことで

MesLang は、セリフを中心に置き、その前後に意味（だれが話すか、ト書き、音、コマなど）を **足していく** 軽いテキストです。

## 旧 Mes から受け継ぐもの・足すもの

残すもの:

- ピース（空行で区切る）
- 行頭の記号
- 前にも後ろにも置ける自由
- 速記の橋渡し（`名前「セリフ」` など）
- ヘッダー（`----`）

足すもの:

- 属性（`:key value`）
- メディアプロファイル（とくに `%` コマ / カット → [呼び分け](05-glossary.md#コマとカットまぎらわしいことば)）
- AI 向けの語彙と読み方ガイド
- 中間データ Medo の明示的な形

旧原稿の移し方は [取り込みガイド](06-mes-compat.md)（[ADR 0006](../decisions/0006-mes-compat-import.md)）をどうぞ。

## v0 ではやらないこと

- 完成形の組版や台本レイアウト（読みやすさは二次ツールの仕事です）
- ゲームの分岐用 DSL（選択肢・ジャンプはコアに入れません）
- 安定した後方互換の保証（実験前提。大きな変更は ADR に残します）
- 専用エディタが必須になること
- 原稿への画像埋め込みや、厳密な音響座標などの重い約束

見送った案の一覧は [用語集](05-glossary.md#採用しないコアに入れない案) にあります。
