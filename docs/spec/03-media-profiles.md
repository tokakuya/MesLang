# メディアプロファイル

MesLang の基本の書き方は、どの作品でも共通です。  
そのうえで、漫画・音声・アニメなど、つくりたいものに合わせて便利な記号を足していきます。  
この「合わせ方」のことを、メディアプロファイルと呼びます。

作品の先頭で、どのプロファイルかを書いておきます。

```mes
profile: manga
----
```

何も書かなければ、音声作品向け（`audio`）として読みます。

## 記号の意味は、どのメディアでもだいたい同じです

行頭の記号（`@` や `#` など）は、漫画でも音声でもアニメでも、**だいたい同じ役割**を持っています。  
変わるのは、現場での呼び方や、どれをよく使うか、くらいです。

たとえば `^` は、漫画では「このコマの構図」、アニメでは「カメラの指示」と書きます。  
どちらも、「どう見せるか」をメモするための記号です。  
`%` も、漫画ならコマ、アニメならカット。どちらも「ひとコマ／ひとカットの区切り」です。

| 記号 | どのメディアでも共通の役割 | 音声作品では | 漫画では | アニメでは |
|------|---------------------------|--------------|----------|------------|
| `@` | だれが話しているか | 話者 | 吹き出しの話者 | 話者 |
| `#` | ト書き・状況・演技のメモ | 演技や状況の指示 | コマの中の動きや空気感 | 演技や状況の指示 |
| `$` | 音のこと | 効果音・BGM・場の声など（よく使う）。話者の声質は `:声質` | コマの中の効果音メモ（任意） | 環境音・効果音のメモ |
| `!` | 音や人の位置 | 左右や遠近のメモ（よく使う） | 使ってもよい | 使ってもよい |
| `&` | タイミング | 字幕や尺合わせのとき | ほぼ使わない | 秒数の目安（よく使う） |
| `%` | 画面の区切り | ふつうは使わない | コマ（番号や短いメモ） | カットの番号 |
| `^` | どう見せるか | ふつうは使わない | 構図・アングル・コマの大きさ | カメラの動きやレンズ感 |
| `*` | 間やテンポ | 使ってもよい | テンポや間のメモ（任意） | 使ってもよい |
| `?` | まだ名前のないメモ | ツール向けの逃げ道 | 同左 | 同左 |

補足:

- 表の「ふつうは使わない」は、書いても大丈夫です。読み手が迷わないよう、残しておけます（くわしくは [こちら](#わからない記号が出てきたとき)）
- 記号そのもののくわしい定義は [02-decorators.md](02-decorators.md) にあります
- ここから先は、各メディアで「特に気をつけたいこと」と、見本だけを書きます

## 漫画（profile: manga）

ネームを書くときの使い方です。  
ここで書くのは、あなたが手を動かす **原稿** です。きれいな完成ネームそのものではありません（ことばの整理は [用語集](05-glossary.md) をどうぞ）。

よく使う記号: `@ # % ^ *`（`$` や `!` も使えます）

書いておくと安心なこと:

- `%` には、コマ番号や、コマの短いメモを書きます
- `^` には、構図やアングルを。`1/2コマ` `2/3コマ` のような大きさのメモも歓迎です
- `#` には、絵にしたい状況や動きを。セリフの演技のニュアンスもここにどうぞ
- `@` は吹き出しの話者です。心の声などなら `@名前 :吹き出し 心の声` のように書けます（かぎかっこ 3 個目でも同じキーに届きます → [かぎかっこ速記](02-decorators.md#かぎかっこ速記任意)）
- `*` は、テンポや間のメモに使えます（なくても大丈夫）
- `$` や `!` は、ネームでも使えますが、必須ではありません
- セリフのないコマも大丈夫です（`%` と `#` / `^` だけでも構いません）。見本: [silent-panels.mes](../../examples/manga/silent-panels.mes)
- ページの区切りは `==`、コマの区切りは `%` です（下の「ページとコマの分け方」）
- **参考画像** は本文には埋め込まず、サンプルのそばにページごと1枚置きます（読み順は右→左・上→下）
- かぎかっこ速記は、漫画では 1=`表情` / 2=`姿勢` / 3=`吹き出し` です（[ADR 0007](../decisions/0007-profile-bracket-keys.md)）
- `:吹き出し` とかぎかっこ 3 個目は同じ行き先です（下の「吹き出しの書き方」）
- 表情と姿勢は、話者に紐づく属性として書きます（下の「表情・姿勢の分け方」）

### 表情・姿勢の分け方（`#` / `:表情` / `:姿勢`）

ネームで迷いやすいので、行き先だけ先に決めます。  
構図は `^`、コマの出来事は `#`、**いまの話者の顔と体**は属性へ、と覚えると楽です。

| 書きたいこと | 行き先 | 例 |
|--------------|--------|-----|
| コマ全体の状況・動き・空気感 | `#` | `#メニューを開いて、目を泳がせる` |
| いまの話者の顔・目・口のニュアンス | `:表情` またはかぎかっこ 1 個目 | `@にか :表情 困り` / `@にか[困り]` |
| いまの話者の体の向き・手・座り方 | `:姿勢` またはかぎかっこ 2 個目 | `@にか :姿勢 前のめり` / `@にか[困り][前のめり]` |
| 構図・アングル・コマの大きさ | `^` | `^にか寄り 1/3コマ` |

`#` に「困った顔で前のめり」とまとめて書いても構いません。  
あとから AI やツールで分けたいときだけ、`:表情` / `:姿勢` に移すと扱いやすくなります。

見本: [cafe-pose.mes](../../examples/manga/cafe-pose.mes)（駅前とは別シチュで、表情・姿勢を厚めに書いた1ページ。末尾に反応コマあり）

### ページとコマの分け方

漫画ネームでは、次のふたつを分けて書きます。

| 記号 | 役割 | 例 |
|------|------|----|
| `==` | **ページ**の区切り（セクション） | `== 1ページ` `== 2ページ` |
| `%` | そのページの中の **コマ** | `%1` `%2` `%改札寄り` |

こう書くと、AI にもツールにも「何ページ目の、何コマ目か」が伝わりやすいです。

```mes
== 1ページ

%1
^俯瞰
#改札前

%2
^寄り
@にか
待たせたな……！

== 2ページ

%1
^引き
#二人並んで歩く
```

**避けたい書き方（失敗例）:**

```mes
// NG: ページ区切りに % を使う
%ページ1
%ページ2

// NG: コマごとに == を立てる（ページが細かく割れすぎる）
== コマ1
%1
== コマ2
%2

// NG: ページをまたいでも == がない（どこで紙が変わるか分からない）
%1
#1ページ目の絵
%6
#じつは2ページ目の絵（読者が分からない）
```

ページが変わったら `==`、コマが進んだら `%`。この対応だけ覚えておけば大丈夫です。

2ページ通しの見本もあります → [station-two-pages.mes](../../examples/manga/station-two-pages.mes)（1ページ目で出会い、2ページ目で駅を出て歩く。各ページの `%` は 1 から数え直します）。  
参考画像を置くときは、ページ（`==`）ごとに1枚です（[ADR 0004](../decisions/0004-manga-reference-images.md)）。

### 吹き出しの書き方（`:吹き出し` とかぎかっこ）

心の声やナレーション吹き出しなど、「ふつうのセリフ吹き出し」と分けたいときは、属性キー **吹き出し** を使います。  
かぎかっこ 3 個目でも、`:吹き出し` でも、**同じ行き先**です。好きなほうで書いてください。

```mes
// かぎかっこ 3 個目
@こいと[からかうように][少し前傾][心の声]

// 同じ意味を :属性 で書く
@こいと :表情 からかうように :姿勢 少し前傾 :吹き出し 心の声
```

見本の `%4` はかぎかっこ側です → [station-name.mes](../../examples/manga/station-name.mes)

1ページ分の見本です（実ファイル: [examples/manga/station-name.mes](../../examples/manga/station-name.mes)）:

```mes
profile: manga
title: 駅前の二人（ネーム）
----
== 1ページ

%1
^俯瞰ぎみ 1/2コマ
#夕方の改札前。人波。にかが焦って入ってくる
$雑踏（小さく）

%2
^にかバストアップ 1/2コマ
@にか :表情 焦り
待たせたな……！

%3
^二人を入れる引き
#こいとが柱の陰から半歩出る
@こいと :表情 呆れ
待ちくたびれましたよ

%4
^こいと寄り（汗） 2/3コマ
@こいと[からかうように][少し前傾][心の声]
罰として、今日は奢ってくださいね

%5
^にか寄り 1/3コマ
@にか :表情 苦笑い
お手柔らかにお願いします
```

```mes
----

%1
^店内引き 1/2コマ
#夕方のカフェ。窓際の席。にかが席に着くところ
$店内BGM（小さく）

%2
^にか全身 1/2コマ
@にか :表情 ほっとした :姿勢 椅子に沈む

%3
^こいとバスト 1/3コマ
@こいと[微笑][肘をついて顎を支える]
メニュー、まだ見てないんですよね？

%4
^にか寄り 1/3コマ
#メニューを開いて、目を泳がせる
@にか :表情 困り :姿勢 前のめり
……甘いもの、全部美味しそうに見えるんだが

%5
^二人横並び 2/3コマ
@こいと :表情 楽しそう :姿勢 少し身を乗り出す

%6
^にかバスト 1/3コマ
@にか[苦笑い][後ずさり気味]

%7
^こいと寄り 1/3コマ

```

`%2` `%4` `%5` `%7` は `:表情` / `:姿勢`、`%3` `%6` はかぎかっこ速記です。どちらでも同じ行き先です。  
`%7` は、やりとりのあとに置く反応コマの例です（状況は `#`、顔と体は属性）。

## 音声作品（profile: audio）

音声ドラマ・ASMR・朗読など向けです。

よく使う記号: `@ # $ ! &`

書いておくと安心なこと:

- `$` には「どんな音か」を書きます。演技の指示は `#` へ
- いま話している人の声の出し方（ささやき・地声など）は `:声質` か、かぎかっこ 2 個目へ（下の「分け方」）
- `!` には、左右や遠近のメモを。厳密な座標まではいりません
- `&` は、字幕や尺合わせが必要なときだけで十分です
- `%` や `^` は、絵がないのでふつうは使いません
- かぎかっこ速記は、音声では 1=`表情` / 2=`声質` です（[ADR 0007](../decisions/0007-profile-bracket-keys.md)）

```mes
profile: audio
title: 駅前
----
@にか[焦り]
#改札を出て、周囲を探す
$雑踏。遠くで電車の発車ベル
!正面やや右
あ、キタキタ。女の子二人を待たせるなんて、失礼だぞ。
```

### 音・声質・ト書きの分け方

音まわりで迷いやすいので、行き先だけ先に決めます。  
どれに書くか迷ったら、「聞こえる出来事か／いまの話者の声か／演技の中身か」で振り分けてください。

| 書きたいこと | 行き先 | 例 |
|--------------|--------|----|
| 環境音・効果音・BGM・他人の声・場のアナウンス | `$` | `$雑踏` `$発車ベル` `$呼びかける声（やや遠く）` |
| いまの話者の声の出し方（ささやき・地声・裏声など） | `:声質` またはかぎかっこ 2 個目 | `@にか :声質 ヒソヒソ` / `@にか[思索][ヒソヒソ]` |
| どう動くか・どんな顔か・気持ちの演技 | `#` や `:表情` | `#少し呆れた感じ` `@にか :表情 焦り` |
| どこで聞こえるか | `!` | `!左寄り` `!遠方` |

旧 Mes では声のメモを `$ヒソヒソ声` のように `$` に書いていたことも多いです。  
**そのままでも構いません**（`$` は壊さず読めます）。あとから話者に紐づけたいときだけ `:声質` へ移すと、AI や台本化が楽になります（取り込み手順は [06-mes-compat.md](06-mes-compat.md)）。

### 音と位置の語彙ガイド（よく使う書き方）

音まわりは、ことばが人によってバラつきやすいです。  
下の言い方を目安にすると、音響さんにも AI にも伝わりやすくなります。  
**必須ではありません。** 思いついたことばで書いて大丈夫です。あとから揃えられます。

#### `$`（音）… 聞こえるもの

| よく書くこと | 例 | メモ |
|--------------|----|------|
| 環境音 | `$雑踏` `$雨音` `$蝉` | 場面の空気づくり |
| 効果音（短い） | `$靴音` `$ドアが開く` `$発車ベル` | 一瞬の出来事 |
| BGM | `$BGM 夕方の駅（控えめ）` | 先頭に `BGM` と書くと区別しやすいです |
| 場の声・他人の声 | `$呼びかける声（やや遠く）` `$駅のアナウンス` | **いまの話者**の声質は `:声質` へ |
| 音量のメモ | `$雑踏（小さく）` `$アナウンス（大きめ）` | カッコ書きで十分です |

`$` には「聞こえるもの」を。  
「いま話している人の声の出し方」は `:声質` に、「どう動くか」「どんな顔か」は `#` や `:表情` に分けましょう。

#### `!`（位置）… どこで聞こえるか / だれの位置か

厳密な座標やパン角度は、いまは決めません（[用語集の見送った案](05-glossary.md#採用しないコアに入れない案)）。  
左右・前後・遠近のメモまでで十分です。

| よく書くこと | 例 | メモ |
|--------------|----|------|
| 正面 | `!正面` | いちばん近い／真ん中のイメージ |
| 左右 | `!左` `!右` `!正面やや右` | ステレオのざっくり位置 |
| 遠近 | `!近づく` `!遠ざかる` `!遠方` | 動きもことばで書いてよいです |
| 上下（任意） | `!上（駅アナウンス）` | 必要なときだけ |

ひとつのピースに `$` と `!` を並べると、「何の音が、どこから」が揃います。

```mes
$遠くで電車の発車ベル
!遠方
$靴音（にか）
!近づく
```

**並びの目安（必須ではありません）:**  
同じピースに `$` と `!` が複数あるときは、**出てきた順で近いもの同士**を組む読み方にします。  
ツールは順序どおりに残しますが、v0 では「この `$` はこの `!`」という硬い紐づけは決めません。迷ったら、音と位置を隣の行に書いてください。

#### `&`（タイミング）… 字幕や尺の目安

音声では、字幕合わせや尺のメモが必要なときだけ使います。なくて大丈夫です。

| よく書くこと | 例 | メモ |
|--------------|----|------|
| 秒数 | `&3.5s` `&約2秒` | 尺の目安 |
| 時刻（字幕用） | `&0:12` `&1:05.2` | タイムコード風で十分です |
| ことばメモ | `&少し間を置いて` | 厳密でなくてよいです |

```mes
@にか
$発車ベル
!遠方
&0:08
あ、キタキタ。
```

`$` / `!` / `&` と `:声質` を同じ場面で並べた例は、見本 [station.mes](../../examples/audio/station.mes) の「改札を出て」をどうぞ。  
セリフのない「音だけの間」は、同じ見本の「ランチへ」にあります（`$` / `!` / `&` / `#` だけで一拍置いてから会話に戻る例です）。

## アニメ（profile: anime）

字コンテやカット表の **下書き（原稿）** 向けです。  
ここで書くのは、あなたが手を動かす **字コンテ下地** です。きれいなカット表や絵コンテそのものではありません（ことばの整理は [用語集](05-glossary.md#原稿と二次出力まぎらわしいことば) をどうぞ）。

よく使う記号: `% ^ & # @ $`（ツール用メモに `?` も使えます）

書いておくと安心なこと:

- `%` にはカットの番号を書きます（漫画のコマと同じく、「画面の区切り」です）
- `^` にはカメラの指示を（寄り・引き・手持ちの揺れなど）。漫画の構図メモと同じく、「どう見せるか」の記号です
- `&` には秒数の目安を
- `#` は演技や状況、`$` は環境音や効果音のメモに使います
- 制作ツールだけが知る ID や仮案は `?` に逃がせます（意味は仕様では固定しません）
- カット表や字コンテ概要に直したいときは、原稿はそのまま。整形は **二次出力** です → [絵コンテ／カット表（仮）](07-conte-table.md)（[ADR 0008](../decisions/0008-conte-table-secondary.md)）

```mes
profile: anime
----
%CUT-012
^寄り → 引き / 手持ちの揺れ
&3.5s
#にかが立ち止まり、振り返る
@にか :表情 不安
……だれか、いないよね？
$街の環境音を少し絞る
?layout A案
```

### カメラと尺の語彙ガイド（よく使う書き方）

字コンテまわりは、カメラのことばが人によってバラつきやすいです。  
下の言い方を目安にすると、作画さんにも AI にも伝わりやすくなります。  
**必須ではありません。** 思いついたことばで書いて大丈夫です。

#### `^`（カメラ）… どう見せるか

| よく書くこと | 例 | メモ |
|--------------|----|------|
| 寄り／引き | `^寄り` `^引き` `^にか寄せ` | 誰に寄るか書くと分かりやすいです |
| 広角／望遠感 | `^広角` `^望遠ぎみ` | レンズ感のメモで十分です |
| 動き | `^ゆっくりパン` `^寄り → 引き` | 矢印や「→」で流れを書いてよいです |
| 手持ち・固定 | `^手持ちの微揺れ` `^固定` | 空気感のメモ |
| 視線の高さ | `^ロー` `^ハイ` | 必要なときだけ |

#### `&`（尺）… このカットの長さ

アニメでは、カットごとの秒数がよく使います。厳密なタイムコードでなくて大丈夫です。

| よく書くこと | 例 | メモ |
|--------------|----|------|
| 秒数 | `&3.5s` `&約2秒` | いちばんよく使う形です |
| ことばメモ | `&少し間を置いて` `&セリフ終わりまで` | 厳密でなくてよいです |
| 時刻（任意） | `&0:12` | 字幕や本編尺と揃えるとき |

```mes
%CUT-012
^寄り → 引き / 手持ちの揺れ
&3.5s
#にかが立ち止まり、振り返る
```

見本全体は [examples/animation/station-conte.mes](../../examples/animation/station-conte.mes) をどうぞ。  
参照パーサでカット表の仮形を見るときは `npm run conte -- ../../examples/animation/station-conte.mes` です。  
形チェックまで含めるときは `--conte --validate`（`validateConteTable`）です。  
AI に字コンテ起こしを頼むときのひな形は [AI 向けガイド](04-ai-reading.md#アニメ字コンテ起こし) にあります。

## ゲーム（VN）（profile: vn）— まだ手をつけていません

ビジュアルノベル向けです。分岐や選択肢は、いまは決めません。  
立ち絵の表情ちがいは、いまのところ `@名前 :表情 …` で足りることが多いです。必要になったら、あらためて決めます。

## わからない記号が出てきたとき

知らない記号の行があっても、できれば消さずに残してください。  
あとから人が読んだり、ツールが解釈したりできるように、原文を大切にします。
