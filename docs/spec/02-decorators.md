# デコレーターと属性

## デコレーターとは

ピースに意味を足す行。行頭の記号で種別が決まる。  
**セリフの前でも後ろでもよい。** 省略してもよい。

```mes
@にか
#振り返りながら
おはよう。

おはよう。
@にか
#振り返りながら
```

上の 2 ピースは（順序情報を除けば）同じ意味内容を表せる。

## コア・デコレーター（全メディア共通）

| 記号 | kind（Medo） | 著者向けの呼び名 | 典型値 |
|------|--------------|------------------|--------|
| `@` `＠` | character | 発言者 / 主体 | キャラ名 |
| `#` `＃` | comment | ト書き・状況・演技指示 | 自然言語 |
| `$` `＄` | sound | 音響 | 効果音・BGM・声質 |
| `!` `！` | position | 位置 / 空間 | 正面・左・遠方 など |
| `&` `＆` | timing | タイミング | WebVTT 風 / 秒 |
| `?` `？` | ext | 拡張（ツール固有） | 非推奨寄り。避難ハッチ |

著者向け文書では日本語の呼び名を優先する。`comment` などは Medo の kind 名（[用語集](05-glossary.md)）。

## メディア拡張デコレーター（プロファイル）

コアを汚さないため、既定では「認識するが必須ではない」。

| 記号 | kind（Medo） | 役割（やさしい言い方） | 著者向けの呼び名 |
|------|--------------|------------------------|------------------|
| `%` | frame | 画面の区切り | コマ / カット |
| `^` | camera | どう見せるか | 構図 / カメラ指示 |
| `*` | beat | 間やテンポ | ビート |

記号の役割は、漫画・音声・アニメでだいたい共通です。  
メディアごとの言い方のちがいは、わかりやすい表にまとめています → [03-media-profiles.md](03-media-profiles.md#記号の意味はどのメディアでもだいたい同じです)。

## 属性構文

キャラ名に `(泣)` をくっつけて識別子を汚す問題（アイコントーク課題）への回答。

### 基本形

デコレーター行の続き、または直後の行に `:key value` を書く。

```mes
@にか :表情 泣 :姿勢 前傾
生ぎたいっ!!!
```

複数属性は同一行でも、改行してもいい。

```mes
@にか
:表情 泣
:姿勢 前傾
生ぎたいっ!!!
```

### キーの規則（v0）

- キーは空白を含まない短い語（日本語可）
- 値は行末まで（同じ行に別 `:key` が来たらそこで区切る）
- よく使うキー（推奨語彙）→ [用語集](05-glossary.md)
  - `表情` / `emotion`
  - `姿勢` / `pose`（キー名に「ポーズ」は使わない）
  - `衣装` / `costume`
  - `視線` / `gaze`
  - `img`（アイコン参照など）
  - `吹き出し`（漫画）

### 速記ブラケット（任意糖衣）

入力負荷を下げるための糖衣。参照パーサでサポートしてよい。

```mes
@にか[泣][前傾]
```

正規化後:

```mes
@にか :表情 泣 :姿勢 前傾
```

v0 の既定キー順（[ADR 0005](../decisions/0005-bracket-default-keys.md)）:

| 位置 | キー |
|------|------|
| 1 個目 | `表情` |
| 2 個目 | `姿勢` |
| 3 個目以降 | `表情2`, `表情3`, … |

プロファイルまたはヘッダーでの上書き表は将来拡張。

## 値の書き方ガイドライン

- 機械処理したい区別（誰が話したか、何コマ目か）→ 記号 + 短い値
- ニュアンス（どう動くか、どう感じるか）→ `#` の自然言語
- 両方必要なら併用する

```mes
@にか :表情 微笑
#口元だけ笑って、目は笑っていない
それで……本当に行くの？
```

## 拡張フィールド `?` について

ツール固有の逃げ道。言語仕様としては「未知の意味を壊さず運ぶ」ことだけ保証する。  
新しい意味が安定したら、専用デコレーターか属性キーへ昇格させる。
