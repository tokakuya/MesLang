# デコレーターと属性

## デコレーターとは

ピースに意味を足す行のことです。行頭の記号で種類が決まります。  
著者向けでは、この記号そのものを **行頭記号** とも呼びます（同じ仲間です → [用語集](05-glossary.md#デコレーターと行頭記号まぎらわしいことば)）。  
**セリフの前でも後ろでも大丈夫です。** 省略しても構いません。

```mes
@にか
#振り返りながら
おはよう。

おはよう。
@にか
#振り返りながら
```

上の 2 つのピースは（順番の情報をのぞけば）同じ内容を表せます。

## どのメディアでも使える記号

全角と半角は同じ意味です（対応表は [用語集](05-glossary.md#全角半角の行頭記号まぎらわしいことば)）。新規は半角が無難ですが、既存の全角を誤り扱いにはしません。

| 記号 | kind（Medo） | やさしい言い方 | よく書く値 |
|------|--------------|----------------|------------|
| `@` `＠` | character | だれが話しているか | キャラ名 |
| `#` `＃` | comment | ト書き・状況・演技 | 自然なことば |
| `$` `＄` | sound | 音のこと | 効果音・BGM・場の声など（[語彙の目安](03-media-profiles.md#音と位置の語彙ガイドよく使う書き方)）。話者の声質は `:声質`。ヘッダーの `$key` とは別（[用語集](05-glossary.md#音声質ヘッダー変数まぎらわしいことば)） |
| `!` `！` | position | 音や人の位置 | 正面・左・遠方 など（同上）。`$` なしでも可（[用語集](05-glossary.md#音の位置と話者の位置まぎらわしいことば)） |
| `&` `＆` | timing | タイミング | 秒数や字幕用の時刻（`*` との呼び分けは [用語集](05-glossary.md#タイミングとビートまぎらわしいことば)） |
| `?` `？` | ext | まだ名前のないメモ | ツール向けの逃げ道 |

文書では、できるだけ日本語の呼び名を使います。  
`comment` などは、中間データ（Medo）側の kind 名です（[用語集](05-glossary.md)）。

## メディアごとの記号（プロファイル）

コアを太らせないため、必須ではありません。書いても大丈夫です。

| 記号 | kind（Medo） | やさしい言い方 | 著者向けの呼び名 |
|------|--------------|----------------|------------------|
| `%` `％` | frame | 画面の区切り | コマ / カット（[呼び分け](05-glossary.md#コマとカットまぎらわしいことば)） |
| `^` `＾` | camera | どう見せるか | 構図 / カメラ指示 |
| `*` `＊` | beat | 間やテンポ | ビート（`&` との呼び分けは [用語集](05-glossary.md#タイミングとビートまぎらわしいことば)） |

記号の役割は、漫画・音声・アニメでだいたい同じです。  
メディアごとの言い方のちがいは、見比べ表にまとめています → [03-media-profiles.md](03-media-profiles.md#記号の意味はどのメディアでもだいたい同じです)。

## 属性の書き方

キャラ名に `(泣)` をくっつけてしまうと、名前そのものが汚れてしまいます。  
その代わりに、属性で分けて書きます。

### 基本形

記号の行の続き、または直後の行に `:key value` を書きます。

```mes
@にか :表情 泣 :姿勢 前傾
生ぎたいっ!!!
```

複数の属性は、同じ行でも、改行しても大丈夫です。

```mes
@にか
:表情 泣
:姿勢 前傾
生ぎたいっ!!!
```

### キーの約束（v0）

- キーは、空白を含まない短い語（日本語でも大丈夫）
- **数字だけで始まるキーは使いません**（`&0:08` のような時刻表記を属性と取り違えないため）
- 値は行末まで（同じ行に別の `:key` が来たら、そこで区切ります）
- よく使うキーは [用語集](05-glossary.md) にあります
  - `表情` / `emotion`
  - `姿勢` / `pose`（キー名に「ポーズ」は使いません）
  - `衣装` / `costume`
  - `視線` / `gaze`
  - `img`（アイコン参照など）
  - `吹き出し`（漫画）
  - `声質`（音声）

### かぎかっこ速記（任意）

打ちやすさのための短縮です。参照パーサでもサポートしてよいものです。  
属性（`:key value`）と同じ行き先です → [用語集](05-glossary.md#かぎかっこ速記と属性まぎらわしいことば)。

```mes
@にか[泣][前傾]
```

正規の形に直すと（コア既定のとき）:

```mes
@にか :表情 泣 :姿勢 前傾
```

#### コア既定の順番（[ADR 0005](../decisions/0005-bracket-default-keys.md)）

| 位置 | キー |
|------|------|
| 1 個目 | `表情` |
| 2 個目 | `姿勢` |
| 3 個目以降 | `表情2`, `表情3`, … |

#### プロファイルごとの行き先（[ADR 0007](../decisions/0007-profile-bracket-keys.md)）

`profile:` を書くと、2 個目以降の行き先がメディアに合わせて変わります。

| 位置 | コア既定 | `audio` | `manga` |
|------|----------|---------|---------|
| 1 個目 | `表情` | `表情` | `表情` |
| 2 個目 | `姿勢` | `声質` | `姿勢` |
| 3 個目 | `表情2` | `表情2` | `吹き出し` |
| 4 個目以降 | `表情3`… | `表情3`… | `表情2`… |

音声の例:

```mes
profile: audio
----
@にか[焦り][ヒソヒソ]
```

→ `@にか :表情 焦り :声質 ヒソヒソ`

漫画の例:

```mes
profile: manga
----
@こいと[呆れ][腕組み][心の声]
```

→ `@こいと :表情 呆れ :姿勢 腕組み :吹き出し 心の声`

#### ヘッダーで上書きするとき

順番を自分で決めたいときは、ヘッダーに `bracket-keys` を書きます（カンマまたは空白区切り）。

```mes
profile: audio
bracket-keys: 表情, 姿勢, 声質
----
```

優先順位は **ヘッダー ＞ プロファイル表 ＞ コア既定** です。  
くわしくは [メディアプロファイル](03-media-profiles.md) もどうぞ。

## 値の書き方の目安

- 機械に分けてほしい区別（だれが話したか、何コマ目か）→ 記号 + 短い値
- ニュアンス（どう動くか、どう感じるか）→ `#` の自然なことば
- 両方が必要なら、いっしょに使います

```mes
@にか :表情 微笑
#口元だけ笑って、目は笑っていない
それで……本当に行くの？
```

## `?` について

ツール固有の逃げ道です。  
言語仕様としては、「知らない意味でも壊さず運ぶ」ことだけを保証します（Medo の kind は `ext`）。  
新しい意味が落ち着いたら、専用の記号や属性キーへ昇格させましょう。

**いつ使うか:** コアの記号（`@ # $ ! & % ^ *`）にまだ載せたくないメモ。  
制作ツールの内部 ID、仮のレイアウト案、あとで消す予定の付箋などです。

```mes
%CUT-002
^にか寄せ / 手持ちの微揺れ
&2s
?layout A案
?bg station_evening
@にか :表情 焦り
おくれた……！
```

上の `?layout` や `?bg` は、言語が意味を決めているわけではありません。  
ツールが「この行は自分用」と拾い、台本やネームには出さない、という使い方を想定しています。  
人にも分かるよう、短いキー＋値の形（`?キー 値`）にしておくと安心です。
