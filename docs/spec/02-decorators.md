# デコレーターと属性

## デコレーターとは

ピースに意味を足す行。行頭の記号で種別が決まる。  
**セリフの前でも後ろでもよい。** 省略してもよい。

```mes
@にか
#振り返りながら
おはよう。

おはよう。
@にか
#振り返りながら
```

上の 2 ピースは（順序情報を除けば）同じ意味内容を表せる。

## コア・デコレーター（全メディア共通）

| 記号 | 名前 | 意味 | 典型値 |
|------|------|------|--------|
| `@` `＠` | character | 発言者 / 主体 | キャラ名 |
| `#` `＃` | comment | ト書き・状況・演技指示 | 自然言語 |
| `$` `＄` | sound | 音響ノート | 効果音・BGM・声質 |
| `!` `！` | position | 音/空間の位置 | 正面・左・遠方 など |
| `&` `＆` | timing | タイミング | WebVTT 風 / 秒 |
| `?` `？` | ext | 拡張（ツール固有） | 非推奨寄り。避難ハッチ |

## メディア拡張デコレーター（プロファイル）

コアを汚さないため、既定では「認識するが必須ではない」。

| 記号 | 名前 | 主なプロファイル | 意味 |
|------|------|------------------|------|
| `%` | frame | manga / anime | コマ / カット番号・内容 |
| `^` | camera | anime / manga | カメラ・アングル・構図 |
| `*` | beat | 共通（任意） | 感情ビート / 演技ビートの短縮 |

詳細は [03-media-profiles.md](03-media-profiles.md)。

## 属性構文

キャラ名に `(泣)` をくっつけて識別子を汚す問題（アイコントーク課題）への回答。

### 基本形

デコレーター行の続き、または直後の行に `:key value` を書く。

```mes
@にか :表情 泣 :姿勢 前傾
生ぎたいっ!!!
```

複数属性は同一行でも、改行してもいい。

```mes
@にか
:表情 泣
:姿勢 前傾
生ぎたいっ!!!
```

### キーの規則（v0）

- キーは空白を含まない短い語（日本語可）
- 値は行末まで（同じ行に別 `:key` が来たらそこで区切る）
- よく使うキー（推奨語彙）:
  - `表情` / `emotion`
  - `姿勢` / `pose`
  - `衣装` / `costume`
  - `視線` / `gaze`
  - `img`（アイコン参照など）

### 速記ブラケット（任意糖衣）

入力負荷を下げるための糖衣。参照パーサでサポートしてよい。

```mes
@にか[泣][前傾]
```

正規化後:

```mes
@にか :表情 泣 :姿勢 前傾
```

ブラケットの解釈表はプロファイルまたはヘッダーで上書き可能にする（将来）。

## 値の書き方ガイドライン

- 機械処理したい区別（誰が話したか、何コマ目か）→ 記号 + 短い値
- ニュアンス（どう動くか、どう感じるか）→ `#` の自然言語
- 両方必要なら併用する

```mes
@にか :表情 微笑
#口元だけ笑って、目は笑っていない
それで……本当に行くの？
```

## 拡張フィールド `?` について

ツール固有の逃げ道。言語仕様としては「未知の意味を壊さず運ぶ」ことだけ保証する。  
新しい意味が安定したら、専用デコレーターか属性キーへ昇格させる。
