# 旧 Mes からの取り込みガイド

以前の [Mes](https://mesdoc.iranika.info/) で書いた脚本を、MesLang に移すときの手順です。  
**コアのパーサはそのままでは柱（`○`）を直しません。** 取り込み前に、下の変換をかけてください（[ADR 0006](../decisions/0006-mes-compat-import.md)）。

## まず知っておくこと

| こと | 説明 |
|------|------|
| だいたいそのまま読める | ピース、`@ # $ ! & ?`、`名前「セリフ」`、ヘッダー `----` はそのままです |
| 柱だけ一手間 | 旧 Mes では行頭の `○` / `◯` をト書き `#` に直していました。MesLang コアでは直しません |
| 章の区切りは `==` | `#第一章` と書いてもト書きのままです。章にしたいときは `== 第一章` へ直します（機械は判断しません） |
| ヘッダーの `$` に注意 | `$title 駅前` のように **ヘッダー** にある `$key value` は変数です。**本文** の `$雑踏` は音です（別もの → [用語集](05-glossary.md#音声質ヘッダー変数まぎらわしいことば)） |
| 属性は MesLang 側の足しもの | `:表情 泣` などは旧ツールでは読めません。あとから足せば大丈夫です |
| 行頭だけが柱 | 前に空白がある `○` や、文の途中の `○` は変換しません。柱は行の先頭に書いてください |
| 似た形の `〇` に注意 | `〇`（数字のゼロに近い形・U+3007）は柱ではありません。機械は直しません。柱は `○` か `◯` です |

## おすすめの手順（音声原稿）

1. ヘッダーに `profile: audio` を足す（なくても音声扱いですが、書いておくと安心です）。旧形の `$title …` はそのままでも、`title: …` に直してもよいです
2. 行頭の `○` / `◯` を `#` に直す（参照パーサの `rewriteMesCompat` でも可）
3. 章・場面の区切りにしたい行を `== …` にする（人の目で確認）
4. 必要なら `@名前 :表情 …` のように属性を足す
5. 話者の声の出し方が `$ヒソヒソ声` のように **本文** の `$` に残っていたら、余裕があるときだけ `:声質`（またはかぎかっこ 2 個目）へ移す（必須ではありません → [音・声質・ト書きの分け方](03-media-profiles.md#音声質ト書きの分け方) / [用語集](05-glossary.md#音声質ヘッダー変数まぎらわしいことば)）
6. 見本や参照パーサで一度パースして、ト書きとセリフが分かれているか見る

## 対応表（よく出るもの）

| 旧 Mes / なじみの書き方 | MesLang での扱い | だれが直すか |
|-------------------------|------------------|--------------|
| `@ # $ ! & ?`（全角も可） | そのまま（kind は同じ）。音声の `&少し間を置いて` も `&` のまま（`*` へ直さない） | 不要 |
| `名前「セリフ」` / タブ / 空白4つ | コアの速記（DoFlat）で `@名前` へ | 不要 |
| `----` ヘッダー | そのまま。`profile:` などを足してよい | 任意 |
| `$title …` などヘッダー変数 | そのまま読める（`title: …` と同じ）。本文の `$音` とは別 | 任意で `key: value` へ |
| `== 場面` | そのままセクション | 不要 |
| 行頭 `○…` / `◯…`（柱） | **ト書き `#…` へ** | 互換レイヤ（推奨） |
| 行頭 `〇…`（似た形・U+3007） | **変換しない**（柱ではない） | 人（`○`/`◯` へ直すか、手で `#` に） |
| `#第一章` を章にしたい | `== 第一章` へ | **人**（公式ヘルパーでは自動にしない） |
| `#少し呆れた感じ`（ト書き） | そのままト書き | 不要 |
| 行頭 `//` のコメントアウト | その行を読み飛ばす | 不要（行の途中の `//` は旧 Mes と差あり。行頭に寄せる） |
| `:表情 泣` など属性 | MesLang の新記法。旧ツール非対応 | 任意で追加 |
| `$ヒソヒソ声` など話者の声メモ | **そのままでも可**（`$` のまま読める）。話者に紐づけたいときだけ `:声質` へ | 任意（人手） |
| `（ト書き）` / `【ト書き】` 行 | コアでは変換しない | ツール固有（任意） |
| `(@名前){{ … }}` 一括付与 | コアには入れない | 使わない / 展開済みテキストへ |

## 変換の例

取り込み前（旧 Mes っぽい柱・章らしい `#`・ヘッダー）:

```mes
$title 駅前
----
#オープニング

○駅前

にか「あ、キタキタ。」
$ヒソヒソ声
$雑踏
!正面

#少し焦り気味
```

互換レイヤ適用後（`○` / `◯` → `#` だけ。ヘッダーの `$title` はそのまま）:

```mes
$title 駅前
----
#オープニング

#駅前

にか「あ、キタキタ。」
$ヒソヒソ声
$雑踏
!正面

#少し焦り気味
```

ここで大事なのは、**`#オープニング` も `#駅前` も、どちらもト書きのまま**だということです。  
機械は「章かどうか」を決めません。章にしたい行だけ、人が `==` へ直します。

章として分け、属性も足した MesLang らしい形:

```mes
profile: audio
title: 駅前
----
== オープニング

#駅前

@にか :表情 焦り :声質 ヒソヒソ
$雑踏
!正面
あ、キタキタ。

#少し焦り気味
```

旧原稿で `$ヒソヒソ声` と書いてあった行は、取り込み直後はそのままで大丈夫です。  
話者に紐づけたいときだけ、上のように `:声質` へ移します（`$` のまま残しても誤りではありません）。  
場の音（`$雑踏`）や位置（`!正面`）は、もともと聞こえる出来事なので `$` / `!` のまま残します。

見本は **三段階** です。機械のあとと、人手のあとを分けて開けます。

| 段階 | ファイル | 中身 |
|------|----------|------|
| 1. 取り込み前 | [mes-import-before.mes](../../examples/audio/mes-import-before.mes) | 行頭 `○` / `◯`、章らしい `#`、旧流儀の `$ヒソヒソ声`、`&少し間を置いて` |
| 2. 機械変換だけ | [mes-import-compat-only.mes](../../examples/audio/mes-import-compat-only.mes) | `rewriteMesCompat` / `--compat` のあと。柱だけ `#`。章も声質もまだ直していない |
| 3. 人手のあと | [mes-import-after.mes](../../examples/audio/mes-import-after.mes) | `==` 化、`:声質` 移動、属性など。場の `$` / `!` と `&` はそのまま |

段階2は、段階1に `--compat` をかけた結果と **同じ文面** になるように揃えてあります（参照パーサの固定テストでも確認）。

### 機械変換が触らないもの（よくある勘違い）

| 書き方 | 互換レイヤのあと | だれが直すか |
|--------|------------------|--------------|
| 行頭の `○駅前` / `◯改札の外` | `#駅前` / `#改札の外` | 機械（推奨） |
| 行頭の `〇駅前`（似た形） | **そのまま**（柱ではない） | 人（`○`/`◯` に直してから互換をかけるか、手で `#` に） |
| `#オープニング`（章にしたい） | **ト書きのまま** | 人（`== オープニング` へ） |
| `#少し呆れた感じ`（演技） | ト書きのまま | 不要 |
| 行の途中や、前に空白がある `○` | **変換しない**（行頭だけが対象） | 人（行頭へ寄せるか手で `#` に） |
| `$ヒソヒソ声`（話者の声メモ） | `$` のまま | 任意で `:声質` へ |
| `$雑踏` / `!正面` | そのまま | 不要 |
| `&少し間を置いて`（尺・ことばの間） | **`&` のまま** | 不要（漫画の `*間` へ直さない → [用語集](05-glossary.md#タイミングとビートまぎらわしいことば)） |
| `*間`（感じとしてのビート） | 取り込み見本では使わない | 漫画ネーム向け。音声取り込みでは `&` 側に寄せる |

### よくあるつまずき: `○` / `◯` と `〇`

見た目が似ている文字が3つあります。

| 文字 | 符号点 | 互換レイヤ |
|------|--------|------------|
| `○` | U+25CB（白い丸） | 行頭なら `#` へ |
| `◯` | U+25EF（大きい丸） | 行頭なら `#` へ |
| `〇` | U+3007（漢数字のゼロに近い形） | **触らない** |

旧 Mes の柱は `○` / `◯` だけです。コピーや変換で `〇` に化けているときは、機械は直しません。目で見て柱用の丸へ直してください。

## 参照パーサでの使い方

```ts
import { rewriteMesCompat } from "./mesCompat.ts";
import { parseMesLang } from "./parse.ts";

const medo = parseMesLang(rewriteMesCompat(oldText));
```

`parseMesLang` 単体では `○` を直しません。取り込みツールだけが `rewriteMesCompat` を挟みます。

参照パーサの CLI では `--compat` で同じ変換をかけられます。  
形が Medo として通るかは、あわせて `--validate` で確かめられます。

```bash
cd packages/meslang-ref
node --experimental-strip-types src/cli.ts --compat --validate ../../examples/audio/mes-import-before.mes
```

### 取り込み後 Medo の目視（任意）

機械変換のあと、出てきた JSON でだいたい次を確認します。

- `version` が `medo/0.0`
- セクションはまだ 1 つで、`title` が空（`#オープニング` は人手で `==` にするまでト書きのまま）
- 行頭だった `○` / `◯` は `kind: "comment"`（`rawMark: "#"`）になっている
- `$ヒソヒソ声` はまだ `kind: "sound"`（話者の `:声質` へ移すのは任意の人手）
- 場の `$雑踏` や `!正面` はそのまま `sound` / `position`
- `&少し間を置いて` は `kind: "timing"` のまま（`beat` / `*` へ直っていない）

機械変換直後の文面は [mes-import-compat-only.mes](../../examples/audio/mes-import-compat-only.mes)、人手の「直しあと」は [mes-import-after.mes](../../examples/audio/mes-import-after.mes) です。  
カット表の目視と同じく、機械形の本命はツール側です。

## いまはやらないこと

- コア DoFlat への `○` 変換の内蔵（境界がにじむため）
- `#…` を自動で `==` に昇格する公式ルール（誤って演技指示まで章になる）
- `〇`（U+3007）を柱として自動変換すること（旧 Mes の柱ではない。誤爆しやすい）
- 旧 Mes 実装の丸コピー

くわしい決定理由は [ADR 0006](../decisions/0006-mes-compat-import.md) をどうぞ。
