# 用語集（v0）

仕様・ADR・サンプル・参照パーサで使う語を揃える。  
英語は Medo / コード上の識別子、日本語は文書と著者向けの呼び名。

## 構造

| 日本語 | 英語 / ID | 意味 |
|--------|-----------|------|
| ヘッダー | header | `----` より前。`profile` や `title` など任意メタデータ |
| ボディ | body | `----` より後の本文 |
| セクション | section | `==` 見出しで区切る任意のまとまり（章・ページなど） |
| ピース | piece | 空行で区切る最小の意味まとまり |
| セリフ | dialogue | ピース内の、デコレーターでも属性でもない行 |
| 中間データ | Medo | パーサが吐く構造化 JSON（`medo/0.0`） |
| kind | kind | Medo 上のデコレーター種別 ID（`character` / `comment` など）。著者向け文書では下表の日本語を優先 |

## 記法

| 日本語 | 英語 / ID | 意味 |
|--------|-----------|------|
| デコレーター | decorator | 行頭記号で種別が決まる意味付け行（`@` `#` `$` など） |
| 属性 | attr / attrs | `:key value`。主に直前デコレーターに付く |
| 糖衣 | sugar | パース前に正規形へ直す入力短縮（`名前「セリフ」` など） |
| DoFlat | `doFlat` | 糖衣展開処理の呼び名（参照パーサ関数名） |
| プロファイル | profile | メディア固有の記号・慣習（`audio` / `manga` / `anime`） |
| 参考画像 | reference image | 漫画サンプルのページから生成した二次画像（1ページ＝1枚）。原稿外でサンプル直下に置く（[ADR 0004](../decisions/0004-manga-reference-images.md)） |

## 原稿と二次出力（混同しやすい）

| 使ってよい語 | 意味 | 注 |
|--------------|------|-----|
| 原稿 | MesLang テキストそのもの | 人が書く入力。サンプル `.mes` も原稿 |
| ネーム用途 / ネーム記述 | `profile: manga` でコマを書くときの用途の通称 | **原稿の一種**。二次ツールの出力ではない |
| 台本 / ネーム / 字コンテ（二次出力） | 整形・組版した読み物 | ツール側の成果。原稿に見栄えを求めない |

文書で「ネーム例」と書くときは **ネーム用途の原稿例** の意味。二次出力の完成ネームと混同しない。

## `#` まわり（混同しやすい）

| 使ってよい語 | 使わない／避ける語 | 注 |
|--------------|-------------------|-----|
| ト書き（`#` / kind `comment`） | 「コメント」だけ言う | コード上の kind は歴史的に `comment`。著者向け文書では **ト書き** を優先 |
| コメントアウト（`//`） | `#` をコメントアウトと呼ぶ | `//` 行はパース対象外 |
| 柱書き | `#` を章見出しの正本と呼ぶ | 旧 Mes 用語。MesLang の正本は **セクション（`==`）** → [ADR 0003](../decisions/0003-hash-is-comment-not-section.md) |

## コア・デコレーターの呼び名

| 記号 | kind（Medo） | 役割（やさしい言い方） | 著者向けの呼び名 |
|------|--------------|------------------------|------------------|
| `@` | character | だれが話しているか | 発言者 / 主体 |
| `#` | comment | ト書き・状況・演技 | ト書き・状況 |
| `$` | sound | 音のこと | 音響 |
| `!` | position | 音や人の位置 | 位置 / 空間 |
| `&` | timing | タイミング | タイミング |
| `?` | ext | まだ名前のないメモ | 拡張（ツール固有） |
| `%` | frame | 画面の区切り | コマ / カット（プロファイル） |
| `^` | camera | どう見せるか | 構図 / カメラ指示（プロファイル） |
| `*` | beat | 間やテンポ | ビート（任意） |

仕様表の英語列は **kind** と書く。著者向けの説明文では日本語の呼び名を使う。  
メディアごとの言い方のちがいは [メディアプロファイルの表](03-media-profiles.md#記号の意味はどのメディアでもだいたい同じです) をどうぞ。
