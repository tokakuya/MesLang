# ADR 0011 — ヘッダーのドル記号は半角も全角も

- 日付: 2026-11-09
- ステータス: Accepted
- 関連: [ADR 0009](0009-header-settings-are-memos.md)、[用語集](../spec/05-glossary.md#ヘッダーのドル記号まぎらわしいことば)、[取り込みガイド](../spec/06-mes-compat.md#ヘッダーのドル記号)

## 文脈

ヘッダーの `$key value` と半角 `$key=value` は、メモとして読むと ADR 0009 で決まっています。  
参照パーサは、次が文書とずれていました。

1. 全角の `＄title 駅前` は変数にならず、題名が消える（本文の `＄雑踏` は音として読めている）
2. `$title: 駅前` は題名 `title` にならず、キー名が `title:` になる
3. 空白の無い `$title:駅前` は、同じコロンなのに変数にならない（1 と 2 で結果が違う）

音声原稿では、IME がドルやコロンを全角にしやすいです。コロンは `title: 駅前`（ドル無し）の区切りなので、ドル行に混ぜると別の書き方になります。

## 決定

1. **ヘッダー変数の印は、半角 `$`（U+0024）と全角 `＄`（U+FF04）の両方**です。キー名にドルは含めません。本文の `＄雑踏` は、これまでどおり音です。
2. **区切りは空白か、半角の `=`** です。`=` の前後の空白も可です。記号の直後の空白（`$ title 駅前`）も、行頭の空白も可です。
3. **コロン（`:` / `：`）は、ドル行の区切りではありません。** `$title: 駅前` も `$title：駅前` も `$title : 駅前` も変数にしません。キー名を `title:` にはしません。ドルを外した `title: 駅前`、または `$title 駅前` / `$title=駅前` に人が直します。
4. **全角の `＝` は区切りにしません**（ADR 0009 のまま）。
5. **`--compat` は直しません。** 全角ドルを半角に揃えず、コロン形も `title:` へ分解しません。
6. 形チェックが通っても、題名が読めたとは限りません（通った＝題名が読めた、ではない）。

## 結果

- 良いこと: 全角ドルの題名が残る。コロンを混ぜた行が、見たことのないキー名にならない
- つらいこと: `$title: 駅前` は、人が直すまで題名になりません
- 次にやること: なし（見本は取り込み三段階のヘッダーに、全角ドルとコロン形を足しただけです）
