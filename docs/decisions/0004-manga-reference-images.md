# ADR 0004 — 漫画プロファイルの参考画像は二次成果物

- 日付: 2026-07-25
- ステータス: Accepted
- 関連: `docs/spec/03-media-profiles.md`、`examples/manga/`、哲学「書きやすさと読みやすさの分離」

## 文脈

`profile: manga` のサンプルは `%` / `^` / `#` / セリフでコマを記述できるが、テキストだけでは構図・表情の感触が伝わりにくい。  
一方で原稿（MesLang）に画像パスやバイナリを混ぜると、速記性と「必須情報ほぼゼロ」が崩れる。

## 決定

1. **参考画像は二次ツール / ドキュメント側の成果物**とする。MesLang コアや Medo に画像必須フィールドを足さない。
2. **生成元はサンプルの MesLang テキスト**（各 `%` ピースの `^` `#` `@` 属性・セリフ）。コマ単位で1枚を基本とする。
3. **表示位置**は、サンプルテキスト（または対応するコマ説明）の **直下**。プロファイル仕様・examples の README など「読む側」に置く。
4. 画像はリポジトリ上 `examples/manga/refs/` に置き、仕様書からは相対リンクする。再生成してよい（確定ネームではない）。
5. 将来のビューアや AI ネーム起こしも同じ慣習に従う: 原稿はテキスト、参考画像は横に／下に並べる。

## 結果

- 良い: 漫画プロファイルのサンプルが「読めるネーム」として伝わる。コアを肥大化させない
- 悪い: 画像とテキストの同期は人手（または生成スクリプト）が必要。キャラ見た目はサンプル間でゆらぐ
- フォロー: 必要なら Medo 外の sidecar（`*.refs.json`）でコマ ID ↔ 画像パスを機械可読にする
