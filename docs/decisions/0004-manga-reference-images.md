# ADR 0004 — 漫画プロファイルの参考画像は二次成果物

- 日付: 2026-07-25
- ステータス: Accepted
- 関連: `docs/spec/03-media-profiles.md`、`examples/manga/`、哲学「書きやすさと読みやすさを分ける」

## 文脈

`profile: manga` の見本は `%` / `^` / `#` / セリフでコマを書けますが、テキストだけではページ全体の感触が伝わりにくいです。  
一方で原稿（MesLang）に画像パスやバイナリを混ぜると、速記性と「必須情報はほぼゼロ」が崩れます。

## 決定

1. **参考画像は二次ツール / ドキュメント側の成果物**とします。MesLang コアや Medo に、画像必須の欄は足しません。
2. **生成単位はページ**（`==` セクションなど）。1ページにつき参考画像1枚。コマごとの分割画像やコマ説明は必須にしません。
3. **コマの読み順は日本の漫画どおり** — 右→左、上→下。横並びコマでは右が先（`%` の若い番号）。吹き出しは縦書きを基本とします。
4. **表示**は見本テキストのすぐ下に、生成した1枚を置きます。人がテキストと画像を見比べられれば十分です。
5. 画像はリポジトリ上 `examples/manga/refs/` に置き、仕様書からは相対リンクします。再生成して構いません（確定ネームではありません）。
6. 将来のビューアや AI ネーム起こしも同じ慣習に従います。原稿はテキスト、参考画像はページ単位で下（または横）に並べます。

## 結果

- 良いこと: 見本が「1ページのネーム」として一目で伝わる。説明の重複が減る
- つらいこと: ページ内の細かいコマ対応は画像側のレイアウト任せ。キャラの見た目は再生成でゆらぐ
- 次にやること: 複数ページの作品例では `==` ごとに1枚を並べる
