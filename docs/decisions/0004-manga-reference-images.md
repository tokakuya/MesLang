# ADR 0004 — 漫画プロファイルの参考画像は二次成果物

- 日付: 2026-07-25
- ステータス: Accepted
- 関連: `docs/spec/03-media-profiles.md`、`examples/manga/`、哲学「書きやすさと読みやすさの分離」

## 文脈

`profile: manga` のサンプルは `%` / `^` / `#` / セリフでコマを記述できるが、テキストだけではページ全体の感触が伝わりにくい。  
一方で原稿（MesLang）に画像パスやバイナリを混ぜると、速記性と「必須情報ほぼゼロ」が崩れる。

## 決定

1. **参考画像は二次ツール / ドキュメント側の成果物**とする。MesLang コアや Medo に画像必須フィールドを足さない。
2. **生成単位はページ**（`==` セクションなど）。1ページにつき参考画像1枚。コマごとの分割画像やコマ説明は必須としない。
3. **表示**はサンプルテキストの直下に、生成した1枚を置く。人がテキストと画像を見比べれば足りる。
4. 画像はリポジトリ上 `examples/manga/refs/` に置き、仕様書からは相対リンクする。再生成してよい（確定ネームではない）。
5. 将来のビューアや AI ネーム起こしも同じ慣習に従う: 原稿はテキスト、参考画像はページ単位で下（または横）に並べる。

## 結果

- 良い: サンプルが「1ページのネーム」として一目で伝わる。説明の重複が減る
- 悪い: ページ内の細かいコマ対応は画像側のレイアウト任せ。キャラ見た目は再生成でゆらぐ
- フォロー: 複数ページの作品例では `==` ごとに1枚を並べる
