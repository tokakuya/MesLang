# ADR 0001 — MesLang v0 の立ち上げ

- 日付: 2026-07-25
- ステータス: Accepted
- 関連: 旧 Mes（tokakuya/Mes, iranika/MeS）

## 文脈

旧 Mes は音声脚本向けにデコレーター速記を確立したが、

1. キャラデコレーターが名前以外の属性（表情など）を持てない
2. 漫画ネーム / 字コンテ向けのコマ・カメラ表現が弱い
3. AI が読む前提の語彙ガイドがなかった
4. 仕様変更時のパーサ改修コストが高く、実験速度が落ちていた

MesLang リポジトリで、実験前提の後継仕様を再設計する。

## 決定

1. **コアは Mes 互換**（ピース、`@ # $ ! & ?`、糖衣、ヘッダー）
2. **属性構文 `:key value` を導入**し、キャラIDと表情等を分離
3. **メディア固有はプロファイル**（`%` `^` など）としてコアの外に出す
4. **仕様・ADR・参照パーサ・サンプル**を同一リポジトリで日次改善する
5. 安定互換より **変更の追跡可能性** を優先する

## 結果

- 良い: 音声と漫画を同じ骨格で試せる。AI 向け文書を同居させられる
- 悪い: 旧ツールはそのままでは新属性を理解しない。互換層が別途必要
- フォロー: M1 で旧 Mes 取り込み方針の ADR を書く
