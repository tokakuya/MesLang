# ADR 0001 — MesLang v0 の立ち上げ

- 日付: 2026-07-25
- ステータス: Accepted
- 関連: 旧 Mes（tokakuya/Mes, iranika/MeS）

## 文脈

旧 Mes は、音声脚本向けに記号速記をしっかり育ててきました。  
ただ、次のような課題がありました。

1. キャラの記号が、名前以外の属性（表情など）を持てない
2. 漫画ネーム / 字コンテ向けのコマ・カメラ表現が弱い
3. AI が読む前提の語彙ガイドがなかった
4. 仕様を変えるたびにパーサ改修の負担が大きく、実験の速度が落ちていた

MesLang リポジトリで、実験前提の後継仕様をあらためて設計します。

## 決定

1. **コアは Mes 互換**（ピース、`@ # $ ! & ?`、速記の橋渡し、ヘッダー）
2. **属性構文 `:key value` を導入**し、キャラ名と表情などを分ける
3. **メディア固有はプロファイル**（`%` `^` など）としてコアの外に出す
4. **仕様・ADR・参照パーサ・見本**を同一リポジトリで日々改善する
5. 安定互換より **変更の追跡しやすさ** を優先する

## 結果

- 良いこと: 音声と漫画を同じ骨格で試せる。AI 向け文書も同居できる
- つらいこと: 旧ツールはそのままでは新しい属性を理解しない。互換層が別途必要
- 次にやること: ~~旧 Mes 取り込み方針~~ → [ADR 0006](0006-mes-compat-import.md)。~~`$` / `!` 語彙・セリフ文字数~~ → 0.0.8 で完了。残りは M2（漫画ネームの安定化）とプロファイル別ブラケットキー
