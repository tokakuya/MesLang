# ADR 0006 — 旧 Mes テキストの取り込み方針

- 日付: 2026-07-26
- ステータス: Accepted
- 関連: [ADR 0001](0001-meslang-v0-bootstrap.md)、[ADR 0003](0003-hash-is-comment-not-section.md)、旧 Mes（[tokakuya/Mes](https://github.com/tokakuya/Mes)）、著者向けガイド [06-mes-compat.md](../spec/06-mes-compat.md)

## 文脈

MesLang のコアは旧 Mes の記号・ピース・ヘッダーを受け継ぎますが、次の点がずれています。

1. 旧 Mes の DoFlat は行頭 `○` / `◯`（柱）を `#` に直してからパースする
2. MesLang コアの `#` は常にト書きで、章区切りは `==` のみ（ADR 0003）
3. MesLang だけが持つ属性（`:key value`）やプロファイル記号は、旧ツールでは読めない

「旧原稿をできるだけそのまま取り込みたい」一方で、コア DoFlat を太らせたくありません。

## 決定

1. **コアの `doFlat` には旧 Mes 固有の変換を入れない**（ADR 0003 を維持）。`○` も `#第一章` もコアでは触らない。
2. **取り込みは「互換レイヤ」の任意処理**とする。参照実装では `rewriteMesCompat` として分離する（既定の `parseMesLang` からは呼ばない）。
3. **v0 で公式に勧める機械変換は次だけ**:
   - 行頭の `○`（U+25CB） / `◯`（U+25EF） → `#`（旧 Mes の `DoFlat_HashiraToComment` と同じ）
   - `〇`（U+3007）は柱ではないので対象外（見た目が似ていても直さない）
4. **章らしい `#…` を `==` へ昇格する変換は、公式ヘルパーに入れない**。人が見て直すか、取り込みツール側の任意ヒューリスティックとする（誤爆しやすいため）。
5. 次は **互換レイヤに入れない**（必要ならツール固有）:
   - `（…）` / `【…】` 行をト書きへ（旧 Mes の CommonScenarioStyle。既定 DoFlat にも無かった）
   - `(@名前){{ … }}` 一括付与などの実験糖衣
   - `〇`（U+3007）→ `#`（旧 Mes の柱ではない）
6. 著者向けの手順と対応表は [06-mes-compat.md](../spec/06-mes-compat.md) に置く。

## 結果

- 良いこと: 旧音声原稿の柱（`○`）を壊さず足場にできる。コアと互換の境界が文書とコードで一致する
- つらいこと: `#第一章` をセクションにしたい場合は手直しが要る
