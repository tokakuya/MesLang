# ADR 0002 — 属性は `:key value` を正とする

- 日付: 2026-07-25
- ステータス: Accepted
- 関連: Ci-en「アイコントーク対応」で挙がった `::img=` 案

## 文脈

`@いらにか（泣）` は、集計すると別キャラになりやすいです。  
HTML 風の `::img=""` は速記性が低く、IME 中の誤入力も起きやすいです。

## 決定

- 正本は **`:key value`**（全角 `：` も同じものとして扱ってよい）
- キーは短い語。値は自然なことばでも大丈夫
- 速記として `@名前[泣]` を許可し、既定では `:表情` に正規化する
- `::img=` は採用しない（必要なら速記の別名としてあとから足す）

## 結果

- タイピング: `:` は記号として安定している。キーを日本語にできる
- パーサ: 行頭の `:`、または記号の行の中の `:` として扱える
- 次にやること: かぎかっこ既定キー順は [ADR 0005](0005-bracket-default-keys.md)。プロファイル別の上書き表はまだ
