# ADR 0002 — 属性は `:key value` を正とする

- 日付: 2026-07-25
- ステータス: Accepted
- 関連: Ci-en「アイコントーク対応」で挙がった `::img=` 案

## 文脈

`@いらにか（泣）` は集計上べつのキャラになりやすい。  
HTML 風 `::img=""` は速記性が低く、IME 中の誤入力も起きやすい。

## 決定

- 正本は **`:key value`**（全角 `：` も同一視してよい）
- キーは短い語。値は自然言語可
- 速記として `@名前[泣]` 糖衣を許可し、既定では `:表情` に正規化
- `::img=` は採用しない（必要なら糖衣エイリアスで後付け）

## 結果

- タイピング: `:` は記号として安定。キーを日本語にできる
- パーサ: 行頭 `:` またはデコレーター行内の `:` トークンとして扱える
- フォロー: ブラケット既定キー順は [ADR 0005](0005-bracket-default-keys.md)。プロファイル別の上書き表は未着手
