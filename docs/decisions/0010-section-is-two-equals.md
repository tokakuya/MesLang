# ADR 0010 — セクションは半角イコール2つ

- 日付: 2026-11-02
- ステータス: Accepted
- 関連: [ADR 0003](0003-hash-is-comment-not-section.md)、[ADR 0006](0006-mes-compat-import.md)、[用語集](../spec/05-glossary.md#セクションはイコール2つまぎらわしいことば)、[取り込みガイド](../spec/06-mes-compat.md#セクションはイコール2つ)

## 文脈

ADR 0003 は、章やページの区切りを `==` に決め、`#第一章` はト書きのままにしました。  
参照パーサの見出し判定は「行が `==` で始まる」だけだったので、次が決まっていませんでした。

1. `=== 場面` も見出しになり、題名が `= 場面` になる（3つ目の `=` を見ていなかった）
2. 全角の `＝＝` は見出しにならないが、文書に書いていなかった
3. セリフの続き行（空行の無い行）の `==` はセリフのまま残るが、「行頭が `==` なら見出し」と読めてしまう
4. 題名の無い `==` は、空の題名と「まだ見出しが無い」が同じ形で、うしろにピースが無いと消えることがあった

音声の場面も、漫画のページも、この行で分かれます。本数を機械が揃えると、セリフに書いた `=` まで場面になります。

## 決定

1. **見出しは、半角の `=` がちょうど2つから始まる行だけ**です（`== オープニング` も `==オープニング` も可。題名の前後の空白は除く）。
2. **行頭の空白は無視します**（全角空白も含む）。境目の `----` とは違います。境目は行頭に空白があると境目になりません。
3. **半角が3つ以上**（`===`）は見出しにしません。行全体がセリフです。題名が `=` で始まるセクションにはしません。
4. **全角の `＝＝` は見出しにしません。** `--compat` は半角に直しません。本数も揃えません。
5. **空行のあと**（または本文の先頭）に置いたときだけ見出しです。セリフの続き行にある `==` は、そのピースのセリフに残します。機械は空行を足して切り離しません。
6. **題名が空の `==` も区切り**です。うしろにピースが無くても、セクションとして残します。
7. 境目より前の `==` は本文の場面になりません。行頭 `//` の行も場面になりません。読み飛ばしたコメントは続き行に数えないので、空行のあとなら、その次の `==` は見出しです。セリフのすぐあと（空行なし）に `//` を挟んでも、`==` はセリフのままです。題名のうしろの `//` は削らず、題名に残します。
8. `#第一章` を `==` へ昇格しない、という ADR 0003 / 0006 はそのままです。

## 結果

- 良いこと: `===` を誤って場面にしない。空行を忘れた `==` が、黙って場面を割らない。題名なしの区切りが消えない
- つらいこと: 全角の `＝＝` や、続き行に書いた `==` は、人が直すまでセリフのままです
- 次にやること: なし（見本本文は、この決定のためには増やしていません）
