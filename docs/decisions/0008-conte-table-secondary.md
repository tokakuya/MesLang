# ADR 0008 — 絵コンテ／カット表は二次出力

- 日付: 2026-07-29
- ステータス: Accepted
- 関連: `docs/spec/03-media-profiles.md`、`docs/spec/07-conte-table.md`、`schema/conte-table.schema.json`、`packages/meslang-ref`、哲学「書きやすさと読みやすさを分ける」

## 文脈

アニメ字コンテの原稿（`profile: anime`）では、`%`（カット）・`^`（カメラ）・`&`（尺）をさっと書けます。  
一方で、制作現場で眺める「カット表」や絵コンテ欄は、読みやすさのための整形です。原稿そのものに表レイアウトを押し込むと、思考を止めない速記が壊れます。

## 決定

1. **絵コンテ／カット表は二次ツールの成果物**とします。MesLang コアや Medo に、表専用の欄は足しません。
2. **入力は Medo のまま**です。参照実装は Medo からカット行を組み立てます（`toConteTable`）。
3. **区切りは `%`（kind `frame`）**です。`%` があるピースで新しいカット行を始め、あとに続く `%` なしピースは同じカットへ足します。
4. **仮の行の形**は `docs/spec/07-conte-table.md` と `schema/conte-table.schema.json` に置きます。破壊的に変えてよい実験形です（版は `conte-table/0.0`）。
5. 漫画の `%`（コマ）にも同じ機械変換をかけられますが、**いまの想定読者は字コンテ／カット表**です。ネーム用の見やすい表は別途考えます。

## 結果

- 良いこと: 原稿は軽いまま、ツール側でカット表を再現できる。Medo を壊さない
- つらいこと: 1ピースに複数 `%` があるなど珍しい書き方は、最初の `%` だけをカット ID にする簡略ルール
