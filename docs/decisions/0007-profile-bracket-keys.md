# ADR 0007 — プロファイル別のかぎかっこキー表

- 日付: 2026-07-27
- ステータス: Accepted
- 関連: [ADR 0005](0005-bracket-default-keys.md)、`docs/spec/02-decorators.md`、`docs/spec/03-media-profiles.md`、参照パーサ `resolveBracketKeys`

## 文脈

ADR 0005 で、かぎかっこ速記 `@名前[…][…]` の **コア既定**（1=`表情` / 2=`姿勢` / 3+=`表情2`…）を固定しました。  
あわせて「プロファイルやヘッダーによる上書きは将来の拡張」と残していました。

音声では 2 個目に「姿勢」より「声の出し方」を書きたくなることが多く、漫画では 3 個目に「吹き出し」種別（心の声など）が欲しくなります。  
コア既定を壊さず、メディアごとの慣習を足す必要があります。

## 決定

1. **コア既定（ADR 0005）は維持する。** プロファイル未指定・未知プロファイル・上書きなしのときの行き先は変わらない。
2. **プロファイル既定表**を次のとおり定める（参照パーサもこれに従う）:

| 位置 | コア既定 | `audio` | `manga` |
|------|----------|---------|---------|
| 1 個目 | `表情` | `表情` | `表情` |
| 2 個目 | `姿勢` | `声質` | `姿勢` |
| 3 個目 | `表情2` | `表情2` | `吹き出し` |
| 4 個目以降 | `表情3`… | `表情3`… | `表情2`… |

   - `anime` / `vn` は当面コア既定のまま（必要になったら表を足す）
   - 音声の `声質` は「ささやき・地声・裏声」など。BGM や環境音はこれまでどおり `$` へ
   - 漫画の 3 個目 `吹き出し` は、心の声・ナレ・外注ぎなど。4 個目以降はコアと同じく `表情2` から振る

3. **ヘッダー上書き**を許可する。キー名は `bracket-keys`（カンマまたは空白区切り）:

   ```mes
   profile: audio
   bracket-keys: 表情, 姿勢, 声質
   ----
   ```

   解決の優先順位: **ヘッダー `bracket-keys` ＞ プロファイル既定表 ＞ コア既定**。  
   表より多くのかぎかっこがあるとき、足りない位置はコア既定と同じく `表情N` で埋める（ヘッダーで 2 個だけ書いた場合の 3 個目は `表情2`）。

4. 明示の `:key value` は、かぎかっこより後からマージしてよい（現状どおり。同じキーなら後勝ちでよい）。

## 結果

- 良いこと: 音声と漫画で「さっと書いたかぎかっこ」の意味が現場に合う。コア既定は壊れない
- つらいこと: 同じ `@名前[a][b]` がプロファイルで 2 個目のキーが変わる（ヘッダーに `profile:` を書く習慣が大切）
- 次にやること: 見本でブラケット速記を使う。AI ガイドに一行注記
