# ADR 0009 — ヘッダー設定はメモ。既定の話者は埋めない

- 日付: 2026-10-19
- ステータス: Accepted
- 関連: [ADR 0006](0006-mes-compat-import.md)、旧 Mes の `MesHeader`（`$default_charactor_name` / `$deco_*` / `$ignore_char`）、[用語集](../spec/05-glossary.md#既定の話者は埋めないまぎらわしいことば)、[取り込みガイド](../spec/06-mes-compat.md)

## 文脈

旧 Mes は、ヘッダーの `$key=value` でパーサの動きを変えていました。

1. `$default_charactor_name=名前` … セリフがあるのに話者行が無いピースへ、その名前を入れる
2. `$deco_charactor` など `$deco_*` … 行頭記号そのものを入れ替える
3. `$ignore_char` … セリフ文字数から、指定した文字（句読点など）を外す

MesLang のヘッダーは、これまで `key: value` と `$key value`（空白区切り）をメタ情報として読んでいました。半角 `=` の行は読み捨てられていて、旧原稿の設定が見えなくなっていました。

音声原稿では、話者が誰か分からない行を機械が埋めない方が安全です。必須情報はほぼゼロ、という哲学とも揃います。

## 決定

1. **ヘッダーはメモ**です。上の3つは実行しません。
   - 既定の話者は埋めません。`@` が無いピースは話者なしのままです
   - 行頭記号は入れ替えません
   - セリフ文字数は、いままでどおり空白だけを除きます。句読点は数えます
2. **半角の `$key=value`（`=` の前後の空白も可）は、`$key value` と同じメモ**として header に残します。互換レイヤ（`rewriteMesCompat` / `--compat`）の仕事ではありません。コアのヘッダー読み取りです。
3. **全角の `＝` は区切りにしません。** 変数にしたいときは半角 `=` か、空白か、`:` に直します。
4. 旧 Mes のキー名 `$default_charactor_name` は、綴りを直さずそのまま残します（`character` には揃えません）。
5. 話者が要るときは、人がそのピースに `@名前` か `名前「セリフ」` を書きます。機械は代行しません。

## 結果

- 良いこと: 旧音声原稿の設定行が Medo の header に残り、消えたように見えません。誰のセリフかは、書いた `@` だけを信じられます
- つらいこと: 旧 Mes で既定話者に頼っていた原稿は、話者なしのピースが残ります。足すのは人手です
- 次にやること: なし（見本本文は、この決定のためには増やしていません）
