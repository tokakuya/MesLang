# ADR 0003 — `#` はト書き。柱書きは `==` セクションへ

- 日付: 2026-07-25
- ステータス: Accepted
- 関連: 旧 Mes の `#第一章` 柱書き、`docs/spec/01-core.md`

## 文脈

旧 Mes では、行頭 `#` が次の二役を担っていました。

1. **柱書き** — `#第一章` のような章・話の区切り
2. **ト書き** — `#少し呆れた感じ` のような状況・演技指示

MesLang v0 では `#` の Medo kind を `comment`（意味: ト書き・状況）とし、文書構造の区切りは `==` セクションに分けました。  
以前の `01-core.md` は旧柱書きを「コメントまたはセクションへ正規化してよい（実装依存）」としており、ツールと AI の解釈が割れる余地がありました。

## 決定

1. **コアの `#` は常にト書き（kind: `comment`）**。値が「第一章」のように見えても、セクションには昇格しません。
2. **セクションの正本は `==` のみ**（例: `== 第一章`）。
3. 旧 Mes の `#第一章` 柱書きをセクションへ寄せる変換は **コアの速記（DoFlat）に入れない**。取り込みツール / 互換プロファイル側の任意処理とします。
4. 行頭 `//` は読み飛ばすコメントアウト。`#` とは別ものとしてことばを分けます。

## 結果

- 良いこと: `#` の意味が一つになり、参照パーサと AI ガイドが一致する
- つらいこと: 旧原稿をそのまま貼ると柱書きがト書きピースになる（取り込み前に `==` へ直すか、互換ツールが必要）
- 次にやること: 互換取り込みガイド（速記一覧）を別 ADR / 文書で書く
