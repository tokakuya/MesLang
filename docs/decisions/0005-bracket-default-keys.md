# ADR 0005 — かぎかっこ速記の既定キー順（v0）

- 日付: 2026-07-25
- ステータス: Accepted
- 関連: [ADR 0002](0002-attribute-syntax.md)、`docs/spec/02-decorators.md`、参照パーサ `extractInlineAttrs`

## 文脈

`@名前[泣][前傾]` 速記は ADR 0002 で許可済みですが、2 個目以降のキー対応が「プロファイルで拡張（未解決）」のままでした。  
参照パーサはすでに「1 個目＝表情、2 個目＝姿勢」で動いており、仕様書と実装のことばがそろっていませんでした。

## 決定

v0 の **既定**（プロファイル未指定・上書きなし）は次のとおりです。

| かぎかっこの位置 | 正規化先キー |
|------------------|--------------|
| 1 個目 | `表情` |
| 2 個目 | `姿勢` |
| 3 個目以降 | `表情2`, `表情3`, …（3 個目が `表情2`） |

注:

1. 著者向け文書では属性キー **姿勢** を正とします。通称の「ポーズ」はキー名にしません（英語エイリアス `pose` は別途書いてよい）。
2. プロファイルやヘッダーによる対応表の上書きは **将来の拡張** のまま残します（本 ADR では定めません）。→ **[ADR 0007](0007-profile-bracket-keys.md) で決定**
3. 明示の `:key value` がある場合は、かぎかっこよりそちらを優先できます（現状の参照パーサは同一デコレーター上でマージします）。

## 結果

- 良いこと: 仕様・用語集・参照パーサが同じ対応表を指す
- つらいこと: 3 個目以降の意味は弱い（表情の追加スロット）。必要ならあとでプロファイル表へ逃がす
