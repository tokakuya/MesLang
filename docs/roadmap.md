# ロードマップ（方針）

カレンダーではなく、達成したい技術マイルストーンで書く。

## M0 — 言語の骨格（いま）

- [x] 哲学・目標の明文化
- [x] MesLang v0 コア仕様ドラフト
- [x] 音声 / 漫画サンプル
- [x] Medo JSON Schema 草案
- [x] 参照パーサ（最小）
- [x] 日次オートメーション用プロンプト

## M1 — 音声 = Mes 互換の実用水準

- [x] `#` はト書き。章区切りの正本は `==`（ADR 0003: コアでは柱書き変換しない）
- [x] ブラケット糖衣の既定キー順（表情 / 姿勢 / 表情N）（ADR 0005）
- 旧 Mes テキストの取り込み方針（糖衣 / 互換ガイド）
- セリフ文字数集計が Medo から再現できること
- 音響デコレーターの語彙ガイド（よく使う `$` / `!`）

## M2 — 漫画ネーム

- `%` コマとページ境界の安定化
- 表情・姿勢属性の実践例を増やす
- AI にネーム起こしを依頼するプロンプト雛形
- [x] サンプルテキストから参考画像を生成し、サンプル直下に表示（ADR 0004）

## M3 — アニメ字コンテ

- カット / カメラ / 尺（`&`）のプロファイル
- 絵コンテ向け出力の仮仕様

## M4 — ゲーム（VN）※低優先

- 選択肢・ラベル・ジャンプはコアに入れない
- 必要になったら別プロファイルとして設計

## 変更の扱い

仕様を変えるときは:

1. `docs/decisions/` に ADR を追加
2. 影響する `docs/spec/` を更新
3. サンプルと参照パーサを追随
4. `CHANGELOG.md` に一行でも残す
